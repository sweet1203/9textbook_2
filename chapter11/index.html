    Chapter 11: 프로젝트 시작! - 질문하고 데이터 모으기¶

    🎯 이 장에서 배우는 것¶

    • 데이터로 탐구할 수 있는 좋은 질문의 조건을 설명할 수 있다
    • 공공데이터포털과 통계청 KOSIS에서 주제에 맞는 데이터를 검색하고 다운로드할 수 있다
    • 수집한 데이터를 오렌지3에 불러와 전처리까지 완료할 수 있다
    • 데이터 수집 과정에서 생기는 문제를 스스로 해결할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분은 지금까지 데이터를 다루는 다양한 도구와 기술을 배웠습니다. 이제 그것을 실제로 사용할 시간입니다.

    탐정이 사건을 해결할 때를 생각해 보세요. 무작정 증거를 모으는 탐정은 없습니다. 먼저 "누가 범인인가?" 라는 핵심 질문을 정하고, 그 질문에 답하기 위한 증거를 모읍니다. 데이터 탐구도 똑같습니다.

    "우리 학교 근처 편의점은 왜 이 시간에 사람이 몰릴까?" "봄에 알레르기가 심해지는 건 정말 꽃가루 때문일까?" "서울에서 자전거 사고가 가장 많이 나는 곳은 어디일까?"

    이런 궁금증을 데이터로 직접 확인할 수 있습니다. 이 장에서는 내가 궁금한 것을 질문으로 만들고, 그 질문에 답할 수 있는 데이터를 찾고, 분석할 준비를 마치는 프로젝트의 첫 번째 단계를 배웁니다.

    📚 핵심 개념¶

    개념 1: 탐구 질문 (Research Question)¶

    비유로 시작

    요리사가 요리를 시작하기 전에 "오늘 뭘 만들까?"를 먼저 정하듯이, 데이터 분석도 "내가 무엇을 알고 싶은가?"를 먼저 정해야 합니다. 이것이 바로 탐구 질문입니다. 질문이 명확하지 않으면 어떤 데이터를 모아야 하는지, 어떻게 분석해야 하는지 방향을 잡을 수 없습니다.

    정확한 정의

    탐구 질문이란 데이터를 수집하고 분석하여 답을 찾을 수 있는 구체적인 질문입니다. 단순한 호기심과는 다릅니다. 반드시 데이터로 확인할 수 있어야 하고, 범위가 명확해야 합니다.

    좋은 탐구 질문의 3가지 조건

    • 구체적이다: "날씨와 사람들의 행동이 관련 있을까?" → ❌ 너무 넓음 / "서울의 기온이 30도를 넘는 날, 한강공원 방문자 수는 평소보다 늘어날까?" → ✅ 구체적
    • 데이터로 확인 가능하다: 실제로 존재하거나 수집 가능한 데이터로 답을 구할 수 있어야 합니다
    • 관심 있는 분야다: 내가 흥미를 느끼는 주제여야 끝까지 탐구할 수 있습니다

    예시로 확인

    graph TD A["❌ 나쁜 질문 예시"] --> B["'사람들은 운동을 좋아할까?'<br/>→ 데이터로 확인하기 어려움"] A --> C["'한국은 행복한 나라일까?'<br/>→ 너무 추상적"] D["✅ 좋은 질문 예시"] --> E["'미세먼지 농도가 높은 날<br/>서울시 대중교통 이용객 수는<br/>늘어날까?'"] D --> F["'연도별 청소년 스마트폰<br/>사용 시간과 수면 시간 사이에<br/>관계가 있을까?'"]

    개념 2: 공공데이터 (Public Data)¶

    비유로 시작

    도서관은 누구나 무료로 이용할 수 있는 공공 공간입니다. 세금으로 운영되기 때문에 모든 시민이 혜택을 누립니다. 공공데이터도 마찬가지입니다. 정부와 공공기관이 국민 세금으로 수집한 데이터를 누구나 자유롭게 사용할 수 있도록 공개한 것입니다.

    정확한 정의

    공공데이터란 국가, 지방자치단체, 공공기관이 생성하거나 관리하는 데이터로, 법률에 따라 국민 누구나 사용할 수 있도록 개방된 정보입니다.

    주요 공공데이터 제공 사이트

    • 공공데이터포털 (data.go.kr): 교통, 환경, 의료, 복지 등 다양한 분야의 데이터 제공
    • 통계청 KOSIS (kosis.kr): 인구, 경제, 사회 분야 공식 통계 데이터
    • 기상청 기상자료개방포털 (data.kma.go.kr): 날씨, 기온, 강수량 등 기상 데이터
    • 서울 열린데이터 광장 (data.seoul.go.kr): 서울시 관련 다양한 데이터

    예시로 확인

    🗂️ 데이터 예시 - 전국 초·중·고 학교 위치 정보 (교육부) - 연도별 교통사고 현황 (도로교통공단) - 지역별 미세먼지 측정 데이터 (한국환경공단) - 월별 도서관 이용자 수 (문화체육관광부)

    개념 3: 데이터 파일 형식 이해하기¶

    비유로 시작

    음식을 담는 그릇에는 접시, 그릇, 컵 등 여러 종류가 있습니다. 데이터도 마찬가지로 저장되는 형식이 다양합니다. 분석 도구인 오렌지3가 읽을 수 있는 형식을 알아야 데이터를 제대로 불러올 수 있습니다.

    정확한 정의와 주요 형식

    • CSV (Comma-Separated Values): 쉼표로 값을 구분한 텍스트 파일. 가장 많이 사용되며 오렌지3에서 바로 불러올 수 있습니다
    • XLSX (Excel 파일): 엑셀로 만든 파일. 오렌지3에서도 불러올 수 있습니다
    • JSON: 웹에서 많이 사용하는 형식. 오렌지3에서 바로 읽기 어려워 CSV로 변환 후 사용합니다

    예시로 확인

    📄 CSV 파일의 생김새 예시:
날짜,지역,미세먼지농도,기온
2024-01-01,서울,45,3.2
2024-01-02,서울,78,2.8
2024-01-03,서울,32,5.1

    💡 알아보기: 공공데이터포털에서 다운로드할 때는 CSV 형식을 선택하면 오렌지3에서 바로 사용하기 가장 편리합니다!

    개념 4: 데이터 전처리 체크리스트¶

    비유로 시작

    요리 재료를 씻고, 껍질을 벗기고, 적당한 크기로 자르는 과정이 없으면 아무리 좋은 재료도 요리하기 어렵습니다. 데이터도 분석 전에 정리하는 과정(전처리) 이 반드시 필요합니다.

    정확한 정의

    데이터 전처리란 수집한 원본 데이터를 분석에 적합한 형태로 정리, 수정, 변환하는 과정입니다.

    프로젝트에서 확인할 전처리 항목

    • 결측값 확인: 비어 있는 칸이 있는지 확인하고 처리
    • 데이터 타입 확인: 숫자인데 문자로 저장된 경우 변환
    • 불필요한 열 제거: 탐구 질문과 관련 없는 열 삭제
    • 이상값 확인: 비정상적으로 크거나 작은 값 확인
    graph LR A[원본 데이터 수집] --> B[오렌지3에 불러오기] B --> C[결측값 확인] C --> D[불필요한 열 제거] D --> E[데이터 타입 정리] E --> F[분석 준비 완료! ✅]

    🔨 따라하기¶

    이제 실제로 탐구 질문을 정하고, 데이터를 찾고, 오렌지3에서 전처리까지 해봅시다. 예시 주제로 "미세먼지가 심한 날, 서울시 지하철 이용객은 늘어날까?" 를 사용합니다.

    Step 1: 나의 탐구 질문 만들기¶

    탐구 질문을 만들기 전에 아래 순서로 생각을 정리해보세요.

    ① 관심 주제 3개 적기

    예시: 날씨, 대중교통, 환경

    ② 각 주제에서 "왜?", "얼마나?", "어디서?" 질문 만들기

    예시: - "미세먼지가 심한 날 사람들은 지하철을 더 많이 탈까?" (날씨 + 대중교통) - "계절에 따라 자전거 대여 횟수가 달라질까?" (날씨 + 교통)

    ③ 좋은 탐구 질문 체크리스트 확인하기

    아래 3가지 질문에 모두 "예"라고 답할 수 있는지 확인하세요.

    • 질문이 구체적인가? (언제, 어디서, 무엇을 포함하는가?)
    • 데이터로 답을 확인할 수 있는가?
    • 내가 정말 궁금한 내용인가?

    💡 생각해보기: "음식이 맛있는 식당은 어디일까?"는 왜 좋지 않은 탐구 질문일까요? '맛있다'는 기준이 주관적이고 데이터로 측정하기 어렵기 때문입니다. "리뷰 수가 1000개 이상인 음식점의 평균 별점은 지역마다 다를까?" 처럼 바꾸면 데이터로 확인할 수 있는 질문이 됩니다.

    Step 2: 공공데이터포털에서 데이터 찾기¶

    ① 사이트 접속

    웹 브라우저를 열고 data.go.kr 에 접속합니다.

    ② 검색하기

    검색창에 탐구 주제와 관련된 키워드를 입력합니다.

    예시 검색어: "서울 지하철 이용객", "미세먼지 농도", "대기오염"

    ③ 검색 결과 필터 설정

    검색 결과 화면에서 아래 필터를 설정하면 원하는 데이터를 빠르게 찾을 수 있습니다.

    • 파일 데이터 탭 선택 (API가 아닌 파일로 내려받기 위해)
    • 확장자: CSV 또는 XLSX 선택
    • 제공기관: 신뢰할 수 있는 공공기관 확인

    ④ 데이터 상세 정보 확인

    데이터를 클릭하면 상세 페이지에서 아래 정보를 꼭 확인하세요.

    • 수집 기간: 내 탐구 질문에 맞는 시기의 데이터인가?
    • 제공 형태: CSV로 받을 수 있는가?
    • 업데이트 주기: 얼마나 최신 데이터인가?

    ⑤ 다운로드

    상세 페이지 하단의 "다운로드" 버튼을 클릭하여 파일을 저장합니다.

    ⚠️ 주의: 파일이 어디에 저장되는지 꼭 확인하세요! 보통 컴퓨터의 "다운로드" 폴더에 저장됩니다.

    Step 3: 통계청 KOSIS에서 데이터 찾기¶

    공공데이터포털 외에 통계청 KOSIS도 매우 유용합니다. 특히 인구, 경제, 사회 관련 주제에 강합니다.

    ① 사이트 접속: kosis.kr 에 접속

    ② 통계표 검색: 상단 검색창에 키워드 입력

    예시: "대기오염", "미세먼지", "기온"

    ③ 원하는 통계표 선택: 검색 결과에서 적합한 표를 선택

    ④ 조회 조건 설정: 시도, 연도 범위 등 원하는 조건 선택 후 "조회" 클릭

    ⑤ 다운로드: 오른쪽 상단 "다운로드" 버튼 → CSV 선택 후 저장

    Step 4: 오렌지3에 데이터 불러오기¶

    이제 다운로드한 CSV 파일을 오렌지3에 불러옵니다.

    ① 오렌지3 실행 후 새 워크플로우 만들기

    ② File 위젯 추가

    좌측 위젯 패널에서 Data → File 위젯을 캔버스로 드래그합니다.

    ③ 파일 연결

    File 위젯을 더블클릭 → 파일 아이콘 클릭 → 다운로드한 CSV 파일 선택

    ④ 인코딩 확인

    한글이 깨져 보이면 인코딩을 변경해야 합니다.

    • File 위젯 옵션에서 인코딩을 UTF-8 또는 EUC-KR 로 변경해보세요
    • 공공데이터포털 파일은 대부분 EUC-KR (또는 CP949) 인코딩입니다

    ⑤ Data Table 위젯으로 확인

    Data → Data Table 위젯을 추가하고 File 위젯과 연결합니다. 데이터가 제대로 불러와졌는지 확인하세요.

    graph LR A[File 위젯] -->|데이터 전달| B[Data Table 위젯] B --> C{확인 항목} C --> D[열 이름이 올바른가?] C --> E[한글이 깨지지 않는가?] C --> F[데이터 행 수가 맞는가?]

    Step 5: 데이터 탐색 및 문제 확인¶

    데이터를 불러왔으면 바로 분석을 시작하기 전에 전체적인 현황을 파악합니다.

    ① Feature Statistics 위젯 연결

    Data → Feature Statistics 위젯을 추가하고 File 위젯과 연결합니다.

    이 위젯에서 확인할 정보: - 결측값(Missing): 비어 있는 값의 개수와 비율 - 데이터 타입: 각 열이 숫자(numeric)인지 텍스트(categorical)인지 - 최솟값, 최댓값: 이상한 값이 있는지 대략적으로 확인

    ② 문제 파악 예시

    예를 들어 "미세먼지 농도" 열에 결측값이 15% 있다면, 이 행들을 어떻게 처리할지 결정해야 합니다.

    Step 6: 기본 전처리 적용하기¶

    ① 불필요한 열 제거

    Data → Select Columns 위젯을 추가합니다.

    • 탐구 질문에 필요한 열만 선택
    • 나머지는 "Ignored" 칸으로 이동

    ② 결측값 처리

    Data → Impute 위젯을 추가합니다.

    • 숫자 데이터의 결측값: 평균값으로 대체 또는 해당 행 제거 선택
    • 결측값이 많으면(30% 이상): 해당 열 자체를 제거 고려

    ③ 최종 확인

    전처리가 완료된 데이터를 다시 Data Table 위젯으로 확인합니다.

    graph TD A[File 위젯<br/>CSV 불러오기] --> B[Feature Statistics<br/>전체 현황 파악] B --> C[Select Columns<br/>필요한 열만 선택] C --> D[Impute<br/>결측값 처리] D --> E[Data Table<br/>최종 확인 ✅]

    📝 전체 워크플로우 요약¶

    이 장에서 완성할 오렌지3 워크플로우는 다음과 같습니다.

    graph LR A["📂 File<br/>(CSV 불러오기)"] --> B["📊 Feature Statistics<br/>(현황 파악)"] A --> C["🔧 Select Columns<br/>(필요한 열 선택)"] C --> D["🩹 Impute<br/>(결측값 처리)"] D --> E["📋 Data Table<br/>(최종 데이터 확인)"]

    💡 정리하기: 이 워크플로우를 저장해두세요! 다음 장에서 이 전처리된 데이터를 사용해서 본격적인 분석을 시작할 것입니다.

    ⚠️ 자주 하는 실수¶

    실수 1: 질문이 너무 넓다

    "건강과 환경의 관계는?"처럼 모든 것을 담으려 하면 어떤 데이터를 찾아야 할지 막막해집니다. 시기, 장소, 대상을 구체적으로 좁혀보세요. "2023년 서울의 초등학교 주변 미세먼지 농도와 결석률의 관계는?"처럼요.

    실수 2: 다운로드한 파일을 찾지 못한다

    데이터를 다운로드했는데 어디 있는지 모르는 경우가 많습니다. 다운로드 전에 저장 위치를 바탕화면이나 정해둔 폴더로 지정하는 습관을 들이세요. 또는 윈도우에서 Ctrl + J를 누르면 다운로드 목록을 볼 수 있습니다.

    실수 3: 인코딩 오류를 무시한다

    한글이 깨져서 ??? 나 이상한 문자가 보이는데 그냥 진행하면, 나중에 지역명이나 항목명을 기준으로 필터링할 때 아무것도 찾을 수 없습니다. 반드시 처음에 인코딩을 올바르게 설정하고 진행하세요.

    실수 4: 전처리 전에 분석을 시작한다

    결측값이 많거나 데이터 타입이 잘못된 상태에서 분석을 하면 결과가 틀리거나 오렌지3가 오류를 냅니다. Feature Statistics로 현황을 먼저 파악하는 습관을 꼭 들이세요.

    실수 5: 탐구 질문을 데이터에 맞게 수정하지 않는다

    원하는 데이터가 없을 수 있습니다. 예를 들어 2010년 이전 데이터가 필요한데 2015년부터만 있을 수 있습니다. 이럴 때는 탐구 질문의 시기를 조정하거나 비슷한 대체 데이터를 찾는 유연함이 필요합니다.

    ✅ 스스로 점검하기¶

    아래 질문에 답할 수 있으면 이 장의 내용을 잘 이해한 것입니다.

    기본 문제

    Q1. 다음 중 좋은 탐구 질문은 무엇인가요? 이유도 설명해보세요.

    • ㉮ "사람들은 왜 운동을 할까?"
    • ㉯ "2023년 서울시에서 미세먼지 주의보가 발령된 날의 자전거 대여 건수는 평소보다 줄어들까?"

    Q2. 공공데이터포털(data.go.kr)에서 CSV 파일을 다운로드할 때, 한글이 깨지는 현상을 방지하려면 오렌지3 File 위젯에서 어떤 설정을 바꿔야 할까요?

    응용 문제

    Q3. 친구가 "우리 동네 맛집이 많은 동네와 적은 동네를 비교하고 싶어"라고 합니다. 이 아이디어를 좋은 탐구 질문으로 바꿔보세요. (구체적, 데이터로 확인 가능, 관심 있는 주제 조건을 모두 충족하도록)

    Q4. Feature Statistics 위젯에서 어떤 열의 결측값이 40%라는 것을 발견했습니다. 이 열을 어떻게 처리하는 것이 좋을까요? 그 이유는 무엇인가요?

    심화 문제

    Q5. 데이터를 찾다 보니 원래 탐구 질문에 딱 맞는 데이터가 없는 상황입니다. 예를 들어 "전국 중학생 수면 시간" 데이터가 없고, "전국 청소년 생활 시간 조사"만 있습니다. 이런 상황에서 어떻게 접근하는 것이 좋을지 서술해보세요.

    🚀 더 해보기¶

    도전 1: 데이터 수집 일지 작성하기

    데이터를 찾는 과정에서 겪은 어려움과 해결 방법을 기록해보세요. 아래 항목을 포함해서 작성하면 됩니다.

    • 처음 찾으려 했던 데이터
    • 찾는 과정에서 생긴 문제 (데이터가 없음, 형식이 다름, 기간이 맞지 않음 등)
    • 문제를 어떻게 해결했는가
    • 최종적으로 사용하기로 한 데이터와 그 이유

    이 기록은 나중에 프로젝트 발표 때 "데이터 수집 과정"을 설명하는 소중한 자료가 됩니다!

    도전 2: 두 개 이상의 데이터 연결해보기

    탐구 질문에 답하려면 두 가지 데이터가 필요한 경우가 많습니다. 예를 들어 "미세먼지 농도"와 "지하철 이용객 수"를 각각 찾아서 날짜를 기준으로 연결해보세요.

    오렌지3에서는 Merge Data 위젯을 사용하면 두 데이터를 공통 열(날짜, 지역명 등)을 기준으로 합칠 수 있습니다.

    graph LR A["📂 File<br/>미세먼지 데이터"] --> C["🔗 Merge Data<br/>(날짜 기준 합치기)"] B["📂 File<br/>지하철 이용객 데이터"] --> C C --> D["📋 Data Table<br/>합쳐진 데이터 확인"]

    도전 3: 다른 지역/나라 데이터 찾기

    서울 데이터와 비교할 다른 지역(부산, 대구 등) 또는 해외 데이터도 찾아보세요. 국제 데이터는 세계보건기구(WHO), 세계은행(World Bank) 오픈데이터에서 무료로 찾을 수 있습니다.

    📌 핵심 개념 정리

    • 탐구 질문: 구체적이고, 데이터로 확인 가능하며, 관심 있는 주제의 질문
    • 공공데이터: 정부와 공공기관이 누구나 사용할 수 있도록 공개한 데이터
    • CSV: 쉼표로 구분된 텍스트 파일 형식으로, 오렌지3에서 가장 사용하기 편리
    • 전처리: 결측값 처리, 불필요한 열 제거 등 분석 전 데이터를 정리하는 과정
