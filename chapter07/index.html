    Chapter 07. 데이터를 그림으로 ① - 기본 차트 마스터¶

    Part 4 | [2권] 데이터 시각화 - 그림으로 말하기

    🎯 이 장에서 배우는 것¶

    • 박스플롯, 히스토그램, 산점도의 특징과 용도를 구분하여 설명할 수 있다.
    • 오렌지3에서 Box Plot, Distributions, Scatter Plot 위젯을 사용하여 데이터를 시각화할 수 있다.
    • 시각화 결과를 보고 데이터의 분포와 관계를 자신의 말로 해석할 수 있다.

    💡 왜 이걸 배우나요?¶

    다음 두 가지 상황을 비교해 봅시다.

    상황 A — 선생님이 말씀하십니다.

    "우리 반 수학 점수 평균은 72점이고, 최솟값은 45점, 최댓값은 98점입니다."

    상황 B — 선생님이 칠판에 그래프를 그립니다.

    점수가 70~80점 사이에 가장 많이 몰려 있고, 낮은 점수대에 몇 명이 뚝 떨어져 있는 그래프가 보입니다.

    어느 쪽이 더 빨리, 더 많이 이해되나요? 대부분의 사람은 그래프를 보는 순간 숫자만 들었을 때보다 훨씬 많은 것을 느낍니다. "아, 대부분 잘 봤는데 몇 명이 많이 어려워했구나"라는 스토리가 자연스럽게 읽히죠.

    데이터 시각화(Data Visualization)란 숫자 데이터를 그래프나 그림으로 바꾸어 패턴, 분포, 관계를 한눈에 파악하게 만드는 작업입니다. 데이터 분석가의 핵심 역량 중 하나이며, 인공지능 모델을 만들기 전에 데이터를 '눈으로 먼저 이해'하는 탐색적 데이터 분석(EDA)의 출발점이기도 합니다.

    이번 시간에는 가장 기본적이고 중요한 세 가지 차트를 배웁니다.

    📌 박스플롯 → 데이터의 퍼짐과 이상값
    📌 히스토그램 → 데이터의 분포 모양
    📌 산점도 → 두 변수 사이의 관계

    📚 핵심 개념¶

    개념 1: 박스플롯 (Box Plot) — 데이터의 '요약 초상화'¶

    비유로 시작¶

    학교 급식에서 학생들이 한 줄로 키 순서로 서 있다고 상상해 보세요. 가장 앞(작은 키)부터 가장 뒤(큰 키)까지 줄을 세운 뒤, 딱 중간에 선 학생의 키가 중앙값입니다. 앞쪽 절반의 중간, 뒤쪽 절반의 중간도 각각 표시합니다. 이 세 지점과 전체 범위를 상자와 선으로 그린 것이 바로 박스플롯입니다.

    정확한 정의¶

    박스플롯은 데이터를 다섯 가지 핵심 수치(5-number summary)로 요약한 그래프입니다.

    graph LR A["최솟값\n(Min)"] --> B["1사분위수\n(Q1, 25%)"] B --> C["중앙값\n(Median, 50%)"] C --> D["3사분위수\n(Q3, 75%)"] D --> E["최댓값\n(Max)"] style A fill:#e8f4f8,stroke:#2196F3 style B fill:#bbdefb,stroke:#2196F3 style C fill:#1976D2,color:#fff,stroke:#0d47a1 style D fill:#bbdefb,stroke:#2196F3 style E fill:#e8f4f8,stroke:#2196F3
    • 상자(Box): Q1에서 Q3까지의 구간 → 데이터의 중간 50%가 여기에 모여 있음
    • 수염(Whisker): 상자 양 끝에서 뻗은 선 → 일반적인 데이터의 범위
    • 점(●): 수염 바깥에 있는 점 → 이상값(Outlier), 다른 데이터와 동떨어진 값

    예시로 확인¶

    우리 반 10명의 수학 점수가 [45, 60, 68, 70, 72, 75, 78, 80, 82, 98]이라면: - 최솟값: 45 / 최댓값: 98 - 중앙값: (72+75)÷2 = 73.5 - Q1: 68 / Q3: 80 - 45와 98은 이상값(다른 학생들과 크게 다름)으로 표시될 수 있음

    💡 박스플롯은 언제 쓰나요?
    여러 그룹을 비교할 때 최고입니다. "남학생 성적 vs 여학생 성적", "A반 vs B반 vs C반"처럼 여러 집단의 분포를 나란히 놓고 비교할 때 단번에 차이가 보입니다.

    개념 2: 히스토그램 (Histogram) — 데이터의 '지형도'¶

    비유로 시작¶

    산의 높이를 표시한 지형도를 본 적 있나요? 높이가 비슷한 지역끼리 같은 색으로 표시되어 "이 산은 중간 높이에 땅이 가장 넓고, 정상 부근은 좁구나"를 알 수 있죠. 히스토그램은 데이터의 지형도입니다. 어떤 값 구간에 데이터가 가장 많이 쌓여 있는지 보여줍니다.

    정확한 정의¶

    히스토그램은 데이터를 일정한 구간(bin)으로 나누고, 각 구간에 해당하는 데이터의 개수(빈도)를 막대 높이로 표현한 그래프입니다.

    graph TD A["전체 데이터 범위"] --> B["구간 나누기\n(bin 설정)"] B --> C["각 구간에\n몇 개의 데이터가\n속하는지 세기"] C --> D["막대 높이 =\n데이터 개수"] D --> E["히스토그램 완성\n→ 분포 모양 확인"] style A fill:#f3e5f5,stroke:#7b1fa2 style E fill:#7b1fa2,color:#fff,stroke:#4a148c

    히스토그램으로 알 수 있는 분포 모양¶

    graph LR subgraph 정규분포 A["🔔 종 모양\n평균 근처에\n가장 많이 모임"] end subgraph 왼쪽치우침 B["📐 왼쪽 꼬리\n높은 값에 데이터\n집중"] end subgraph 오른쪽치우침 C["📐 오른쪽 꼬리\n낮은 값에 데이터\n집중"] end subgraph 균등분포 D["▬ 납작한 모양\n모든 구간에\n고르게 분포"] end

    💡 히스토그램은 언제 쓰나요?
    하나의 변수가 어떤 값에서 많이 나타나는지, 분포가 대칭인지 치우쳐 있는지를 볼 때 씁니다. "우리 반 수학 점수는 어느 구간에 학생이 가장 많은가?"처럼 하나의 연속형 변수의 분포를 탐색할 때 최고입니다.

    개념 3: 산점도 (Scatter Plot) — 두 변수의 '관계 지도'¶

    비유로 시작¶

    키가 클수록 발 사이즈도 클까요? 공부 시간이 많을수록 성적이 높을까요? 이런 "A가 크면 B도 클까?"라는 질문에 답할 때 산점도를 그립니다. X축에 A, Y축에 B를 놓고, 각 데이터를 좌표 위에 점으로 찍으면 됩니다. 점들이 모인 모양이 두 변수의 관계를 보여줍니다.

    정확한 정의¶

    산점도는 두 변수의 값을 각각 X축과 Y축으로 하여 각 데이터 포인트를 점으로 표시한 그래프입니다. 점들의 패턴으로 두 변수 간 상관관계를 시각적으로 파악합니다.

    graph TD A["산점도 패턴 분류"] A --> B["양의 상관관계\nX↑ → Y↑\n점들이 왼쪽 아래에서\n오른쪽 위로 모임"] A --> C["음의 상관관계\nX↑ → Y↓\n점들이 왼쪽 위에서\n오른쪽 아래로 모임"] A --> D["상관관계 없음\nX와 Y가 무관\n점들이 랜덤하게 흩어짐"] style B fill:#e8f5e9,stroke:#388e3c style C fill:#ffebee,stroke:#d32f2f style D fill:#fff8e1,stroke:#f57f17

    💡 산점도는 언제 쓰나요?
    두 개의 숫자형 변수 사이의 관계를 볼 때 씁니다. 점에 색상이나 크기를 추가하면 세 번째 변수 정보까지 담을 수 있어 더욱 강력해집니다.

    개념 4: 세 차트 한눈에 비교¶

    flowchart TD Q["어떤 차트를 써야 할까?"] Q --> Q1["변수가 몇 개?"] Q1 -->|"1개"| Q2["무엇을 보고 싶나?"] Q1 -->|"2개"| B["산점도\nScatter Plot\n두 변수의 관계 확인"] Q2 -->|"분포 모양"| A1["히스토그램\nHistogram\n어느 값에 많이 모여 있나?"] Q2 -->|"요약 + 이상값 + 그룹 비교"| A2["박스플롯\nBox Plot\n5가지 핵심 수치 요약"] style A1 fill:#e3f2fd,stroke:#1565c0 style A2 fill:#fce4ec,stroke:#c62828 style B fill:#e8f5e9,stroke:#2e7d32

    🔨 따라하기 — 오렌지3로 세 가지 차트 그리기¶

    📌 준비물: 오렌지3 설치 완료, iris 데이터셋(오렌지3 기본 제공)

    Step 1: 오렌지3 실행 및 데이터 불러오기¶

    1. 오렌지3를 실행합니다.
    2. 왼쪽 위젯 패널에서 "File" 위젯을 찾아 캔버스로 드래그합니다.
    3. File 위젯을 더블클릭 → "Browse documentation datasets" 클릭 → iris.tab 선택 → OK
    4. File 위젯 아래에 붓꽃(iris) 데이터 150개가 로드되었음을 확인합니다.

    🌸 iris 데이터란? 붓꽃 150송이의 꽃잎 길이, 꽃잎 너비, 꽃받침 길이, 꽃받침 너비와 품종(Setosa / Versicolor / Virginica) 정보가 담긴 유명한 연습용 데이터셋입니다.

    Step 2: 박스플롯 그리기¶

    1. 위젯 패널 → "Visualize" 탭 → "Box Plot" 위젯을 캔버스로 드래그
    2. File 위젯의 출력 단자를 Box Plot의 입력 단자로 연결 (선을 드래그하여 연결)
    3. Box Plot 위젯을 더블클릭하여 창을 엽니다.
    4. 설정 패널에서:
    5. Variable: petal length 선택
    6. Subgroup: iris (품종) 선택
    7. 세 품종의 꽃잎 길이 분포가 나란히 표시되는 박스플롯을 확인합니다.

    확인해야 할 것: - Setosa의 상자가 가장 아래쪽에, Virginica가 가장 위쪽에 위치하는가? - 상자의 크기(Q1~Q3 범위)가 품종마다 다른가? - 이상값(동그라미 점)이 보이는가?

    Step 3: 히스토그램 그리기¶

    1. 위젯 패널 → "Visualize" 탭 → "Distributions" 위젯을 캔버스로 드래그
    2. File 위젯과 Distributions 위젯을 연결합니다.
    3. Distributions 위젯을 더블클릭합니다.
    4. 설정 패널에서:
    5. Variable: sepal width 선택
    6. Group by: iris 선택 (품종별로 색상 구분)
    7. 히스토그램이 나타납니다.

    확인해야 할 것: - 분포가 종 모양(정규분포)에 가까운가, 치우쳐 있는가? - 어느 꽃받침 너비 구간에 데이터가 가장 많이 몰려 있나요? - 품종별로 분포 모양이 다른가요?

    Step 4: 산점도 그리기¶

    1. 위젯 패널 → "Visualize" 탭 → "Scatter Plot" 위젯을 캔버스로 드래그

    📝 전체 코드¶

    # 필요한 라이브러리 불러오기
import matplotlib.pyplot as plt
import matplotlib
import seaborn as sns
from sklearn.datasets import load_iris
import pandas as pd

# 한글 폰트 설정 (Windows)
matplotlib.rcParams['font.family'] = 'Malgun Gothic'
matplotlib.rcParams['axes.unicode_minus'] = False

# iris 데이터 불러오기
iris_data = load_iris()
df = pd.DataFrame(iris_data.data, columns=iris_data.feature_names)
df['species'] = [iris_data.target_names[i] for i in iris_data.target]

# 그래프 3개를 한 화면에 배치
fig, axes = plt.subplots(1, 3, figsize=(15, 5))
fig.suptitle('Iris 데이터 시각화 3종 세트', fontsize=14, fontweight='bold')

# ① 박스플롯 - 품종별 꽃잎 길이 비교
species_groups = [df[df['species'] == s]['petal length (cm)'].values
                  for s in iris_data.target_names]
axes[0].boxplot(species_groups, labels=iris_data.target_names)
axes[0].set_title('① 박스플롯: 품종별 꽃잎 길이')
axes[0].set_xlabel('품종')
axes[0].set_ylabel('꽃잎 길이 (cm)')

# ② 히스토그램 - 꽃받침 너비 분포
colors = ['#FF6B6B', '#4ECDC4', '#45B7D1']
for i, species in enumerate(iris_data.target_names):
    subset = df[df['species'] == species]['sepal width (cm)']
    axes[1].hist(subset, alpha=0.6, label=species,
                 color=colors[i], bins=12, edgecolor='white')
axes[1].set_title('② 히스토그램: 꽃받침 너비 분포')
axes[1].set_xlabel('꽃받침 너비 (cm)')
axes[1].set_ylabel('개수')
axes[1].legend()

# ③ 산점도 - 꽃잎 길이 vs 꽃잎 너비
for i, species in enumerate(iris_data.target_names):
    subset = df[df['species'] == species]
    axes[2].scatter(subset['petal length (cm)'],
                    subset['petal width (cm)'],
                    label=species, color=colors[i],
                    alpha=0.7, s=50)
axes[2].set_title('③ 산점도: 꽃잎 길이 vs 너비')
axes[2].set_xlabel('꽃잎 길이 (cm)')
axes[2].set_ylabel('꽃잎 너비 (cm)')
axes[2].legend()

plt.tight_layout()
plt.savefig('iris_visualization.png', dpi=150, bbox_inches='tight')
plt.show()
print("저장 완료: iris_visualization.png")

    ⚠️ 자주 하는 실수¶

    실수 1: 히스토그램을 막대 그래프와 혼동한다

    히스토그램의 막대는 서로 붙어 있습니다. 이것이 중요한 이유는, 히스토그램의 X축은 '연속적인 수치 구간'이기 때문입니다. 반면 막대 그래프(bar chart)는 '서로 독립적인 범주'를 비교하므로 막대 사이에 간격이 있습니다. "국어, 수학, 영어 점수 비교"는 막대 그래프, "수학 점수의 분포"는 히스토그램입니다.

    실수 2: 산점도의 상관관계를 인과관계로 착각한다

    산점도에서 양의 상관관계가 보여도, 그것이 "A가 B의 원인"이라는 뜻은 아닙니다. 예를 들어, 아이스크림 판매량과 익사 사고 수는 양의 상관관계가 있지만, 아이스크림이 익사를 유발하는 게 아닙니다. 둘 다 '더운 날씨'라는 공통 원인 때문입니다. 상관관계(correlation) ≠ 인과관계(causation)을 항상 기억하세요.

    실수 3: 박스플롯에서 이상값을 무조건 제거하려 한다

    이상값(아웃라이어)이 보인다고 해서 무조건 지우면 안 됩니다. 이상값은 데이터 입력 오류일 수도 있지만, 진짜 특별한 케이스일 수도 있습니다. 예를 들어 전교 1등 학생의 성적이 이상값으로 보인다면, 그 학생은 지우면 안 됩니다! 이상값을 발견했을 때는 "왜 이 값이 다른가?"를 먼저 조사하는 것이 순서입니다.

    실수 4: 오렌지3에서 위젯을 연결하지 않고 실행한다

    File 위젯에서 데이터를 불러왔더라도, Box Plot 위젯과 연결선(엣지)을 그어야 데이터가 전달됩니다. 위젯이 회색으로 보이거나 차트가 비어 있다면, 연결선이 끊어져 있거나 없는 것입니다. 위젯의 출력 단자(오른쪽 작은 점)에서 입력 단자(왼쪽 작은 점)로 드래그하여 연결하세요.
