    Chapter 04. 오렌지3 첫 만남 - 나의 데이터 분석 도구¶

    🎯 이 장에서 배우는 것¶

    • 오렌지3를 설치하고 기본 인터페이스의 구성 요소를 설명할 수 있다.
    • 위젯을 캔버스에 배치하고 연결하여 간단한 워크플로를 만들 수 있다.
    • 내장 Iris 데이터셋을 불러와 Data Table 위젯으로 데이터를 확인할 수 있다.

    💡 왜 이걸 배우나요?¶

    데이터 분석이라고 하면 어렵고 복잡한 코딩이 먼저 떠오르지 않나요? 실제로 많은 사람들이 "나는 코딩을 못하니까 데이터 분석도 못하겠지"라고 생각하고 포기합니다.

    하지만 세상에는 레고 블록처럼 블록을 연결하는 것만으로 데이터를 분석할 수 있는 도구가 있습니다. 바로 오렌지3(Orange3) 입니다.

    오렌지3는 슬로베니아의 류블랴나 대학교에서 만든 오픈소스 데이터 분석 도구입니다. 전 세계 수백만 명의 연구자, 학생, 데이터 과학자들이 사용하고 있으며, 마우스 클릭만으로 데이터를 불러오고, 분석하고, 시각화할 수 있습니다.

    🧡 오렌지3를 배워야 하는 이유 - 코드 한 줄 없이도 머신러닝까지 경험할 수 있어요. - 데이터 흐름을 눈으로 볼 수 있어서 분석 과정을 직관적으로 이해할 수 있어요. - 나중에 파이썬 코딩을 배울 때 "이게 코드로 이렇게 되는구나!" 하고 연결해서 이해할 수 있어요.

    📚 핵심 개념¶

    개념 1: 오렌지3란 무엇인가?¶

    비유로 시작: 요리를 생각해 보세요. 훌륭한 요리사가 되려면 칼질, 불 조절, 레시피 암기 등 수많은 기술이 필요합니다. 하지만 요즘에는 "에어프라이어"처럼 버튼 하나로 맛있는 요리를 만들 수 있는 도구도 있죠. 오렌지3는 데이터 분석 세계의 에어프라이어입니다. 복잡한 코딩 기술 없이도 원하는 분석 결과를 만들어 낼 수 있거든요.

    정확한 정의: 오렌지3는 시각적 프로그래밍 방식의 데이터 분석 및 머신러닝 플랫폼입니다. 사용자는 "위젯(Widget)"이라는 기능 블록을 화면에 끌어다 놓고, 화살표로 연결하는 것만으로 데이터 분석 파이프라인을 구성할 수 있습니다.

    예시로 확인:

    flowchart LR A["📂 File\n(데이터 불러오기)"] --> B["📊 Data Table\n(데이터 보기)"] --> C["📈 Scatter Plot\n(산점도 그리기)"] style A fill:#FF8C00,color:#fff style B fill:#4CAF50,color:#fff style C fill:#2196F3,color:#fff

    위 그림처럼 세 개의 위젯을 연결하면, 파일에서 데이터를 읽고 → 표로 보고 → 그래프까지 그리는 과정이 완성됩니다. 코드 한 줄 없이요!

    개념 2: 위젯(Widget)과 워크플로(Workflow)¶

    비유로 시작: 레고 블록 세트를 떠올려 보세요. 각각의 레고 블록은 정해진 모양과 기능이 있고, 블록을 연결하는 방식에 따라 집도 되고 자동차도 됩니다. 오렌지3에서 위젯은 레고 블록이고, 위젯들을 연결해 만든 전체 구조물이 워크플로입니다.

    정확한 정의: - 위젯(Widget): 특정 기능을 수행하는 하나의 분석 단위. 데이터를 불러오거나, 가공하거나, 시각화하는 등 각자의 역할이 있습니다. - 워크플로(Workflow): 여러 위젯을 연결해서 만든 데이터 분석 흐름 전체. 데이터가 왼쪽에서 오른쪽으로 흘러가며 처리됩니다.

    예시로 확인: 위젯의 종류는 크게 네 가지로 나뉩니다.

    mindmap root((위젯 종류)) Data File Data Table CSV Import Visualize Scatter Plot Box Plot Distributions Model Linear Regression kNN Random Forest Evaluate Test and Score Confusion Matrix

    개념 3: 캔버스(Canvas)와 인터페이스 구성¶

    비유로 시작: 화가가 그림을 그리는 하얀 도화지를 "캔버스"라고 하죠. 오렌지3의 캔버스도 똑같습니다. 아무것도 없는 하얀 공간에 위젯을 올려놓고, 선으로 연결해서 나만의 분석 그림을 완성하는 곳입니다.

    정확한 정의: 오렌지3의 화면은 크게 세 영역으로 구성됩니다.

    graph TD A["오렌지3 전체 화면"] A --> B["왼쪽: 위젯 패널\n(Widget Panel)\n사용 가능한 모든\n위젯 목록"] A --> C["가운데: 캔버스\n(Canvas)\n위젯을 배치하고\n연결하는 작업 공간"] A --> D["아래: 상태창\n(Status Bar)\n현재 처리 상태와\n오류 메시지 표시"] style B fill:#FFE0B2 style C fill:#E8F5E9 style D fill:#E3F2FD

    각 영역의 역할: - 위젯 패널: 왼쪽에 위치. 카테고리별로 정리된 위젯 목록이 있습니다. 원하는 위젯을 캔버스로 드래그하거나 더블클릭하면 캔버스에 추가됩니다. - 캔버스: 가운데의 넓은 흰 공간. 실제 분석 작업이 이루어지는 무대입니다. - 상태창: 화면 맨 아래. 데이터가 몇 개 처리되었는지, 오류가 있는지 실시간으로 보여줍니다.

    개념 4: Iris 데이터셋¶

    비유로 시작: 처음 수영을 배울 때 깊은 바다가 아닌 수영장에서 시작하죠. Iris 데이터셋은 데이터 분석을 처음 배울 때 쓰는 "수영장" 같은 데이터입니다. 작고 깔끔하고 다루기 쉬워서 전 세계 데이터 교육에서 가장 많이 쓰이는 예제 데이터입니다.

    정확한 정의: Iris(붓꽃) 데이터셋은 1936년 영국 통계학자 로널드 피셔가 수집한 데이터로, 세 종류의 붓꽃(Setosa, Versicolor, Virginica)에 대해 꽃잎과 꽃받침의 길이/너비를 측정한 150개의 데이터입니다.

    예시로 확인: 각 행(row)은 꽃 한 송이를 의미하고, 각 열(column)은 측정값입니다.

    • sepal length: 꽃받침 길이 (단위: cm)
    • sepal width: 꽃받침 너비 (단위: cm)
    • petal length: 꽃잎 길이 (단위: cm)
    • petal width: 꽃잎 너비 (단위: cm)
    • iris: 붓꽃 종류 (Setosa / Versicolor / Virginica)

    총 150행 × 5열의 표 형태 데이터입니다.

    🔨 따라하기¶

    Step 1: 오렌지3 설치하기¶

    준비물: 인터넷이 연결된 컴퓨터 (Windows / Mac / Linux 모두 가능)

    1. 웹 브라우저를 열고 주소창에 https://orangedatamining.com 을 입력합니다.
    2. 홈페이지 상단의 "Download" 버튼을 클릭합니다.
    3. 자신의 운영체제에 맞는 설치 파일을 다운로드합니다.
    4. Windows: .exe 파일
    5. Mac: .dmg 파일
    6. 다운로드한 파일을 실행하고, "다음(Next)" 버튼을 계속 눌러 기본 설정으로 설치합니다.
    7. 설치가 완료되면 바탕화면의 오렌지3 아이콘🍊을 더블클릭해서 실행합니다.

    ⚠️ 설치 중 주의사항: 설치 폴더 경로에 한글이 포함되면 오류가 날 수 있습니다. 설치 경로는 기본값(C:\Program Files\Orange)을 그대로 사용하세요.

    Step 2: 첫 화면 탐색하기¶

    오렌지3를 실행하면 Welcome 화면이 나타납니다. "New" 를 클릭하거나 "Close" 버튼을 눌러 메인 화면으로 이동합니다.

    메인 화면에서 다음 세 가지를 찾아보세요.

    • 왼쪽 패널: 위젯 목록이 카테고리별로 정렬되어 있습니다. "Data", "Visualize", "Model" 등의 카테고리를 클릭해서 펼쳐보세요.
    • 가운데 캔버스: 지금은 비어 있는 흰 공간입니다. 여기에 위젯을 배치할 것입니다.
    • 상단 메뉴: File, Edit, View, Options 등의 메뉴가 있습니다.

    💡 알아보기: 위젯 패널이 보이지 않는다면? 화면 왼쪽 가장자리에 작은 화살표(▶)가 있을 수 있습니다. 클릭하면 패널이 나타납니다.

    Step 3: 첫 번째 위젯 배치하기 — Datasets¶

    이제 Iris 데이터셋을 불러와 보겠습니다.

    1. 왼쪽 위젯 패널에서 "Data" 카테고리를 클릭해서 펼칩니다.
    2. "Datasets" 위젯을 찾아 캔버스 가운데로 드래그(마우스로 끌어다 놓기) 합니다.
    3. 캔버스에 "Datasets" 위젯 아이콘이 생성됩니다.
    4. 해당 위젯을 더블클릭하면 설정 창이 열립니다.
    5. 검색창에 "iris" 를 입력하면 Iris 데이터셋이 목록에 나타납니다.
    6. "iris" 를 클릭해서 선택하고 오른쪽 아래의 "Send" 버튼을 클릭합니다.

    💡 알아보기: Datasets 위젯은 오렌지3에 내장된 예제 데이터를 불러오는 위젯입니다. 인터넷 연결이 필요할 수 있으니, 처음 불러올 때 잠깐 기다려주세요.

    Step 4: Data Table 위젯 연결하기¶

    데이터를 불러왔으니 이제 그 데이터를 표 형태로 확인해 봅시다.

    1. 위젯 패널의 "Data" 카테고리에서 "Data Table" 위젯을 찾습니다.
    2. 캔버스에서 Datasets 위젯 오른쪽에 Data Table 위젯을 드래그합니다.
    3. 이제 두 위젯을 연결해야 합니다. Datasets 위젯의 오른쪽 가장자리에 마우스를 올리면 작은 점(연결 포인트)이 나타납니다.
    4. 그 점을 클릭한 채로 Data Table 위젯까지 드래그하면 두 위젯 사이에 선(연결선) 이 생깁니다.
    5. Data Table 위젯을 더블클릭하면 표 형태의 데이터가 나타납니다.
    flowchart LR A["🗄️ Datasets\n(iris 선택됨)"] -->|"Data"| B["📋 Data Table\n(150행 × 5열)"] style A fill:#FF8C00,color:#fff style B fill:#4CAF50,color:#fff

    Data Table에서 확인할 수 있는 내용: - 총 150개의 행: 붓꽃 150송이의 측정 데이터 - 5개의 열: sepal length, sepal width, petal length, petal width, iris - 마지막 열 iris: 세 가지 종류(Iris setosa / Iris versicolor / Iris virginica)

    Step 5: Scatter Plot으로 시각화해 보기¶

    데이터를 눈으로 봤으니, 이번에는 그래프도 연결해 봅시다.

    1. 위젯 패널의 "Visualize" 카테고리에서 "Scatter Plot" 위젯을 찾아 캔버스에 드래그합니다.
    2. Data Table 위젯의 오른쪽 연결 포인트에서 Scatter Plot 위젯으로 선을 연결합니다.
    3. Scatter Plot 위젯을 더블클릭하면 산점도 그래프가 나타납니다.
    4. 왼쪽 설정 패널에서 Axis X를 "petal length", Axis Y를 "petal width"로 바꿔보세요.
    5. Color를 "iris"로 설정하면 세 종류의 꽃이 각각 다른 색깔로 표시됩니다.

    세 종류의 붓꽃이 그래프에서 확연히 구분되는 것을 볼 수 있습니다. 이것이 바로 데이터 시각화의 힘입니다!

    Step 6: 파이썬으로 같은 작업 해보기 (비교 학습)¶

    오렌지3에서 한 작업을 파이썬 코드로 하면 어떻게 될까요? 비교해서 보겠습니다.

    # 오렌지3의 Datasets + Data Table + Scatter Plot과 동일한 작업

# 필요한 라이브러리 불러오기
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris

# 1단계: 데이터 불러오기 (Datasets 위젯과 동일)
iris = load_iris()
df = pd.DataFrame(iris.data, columns=iris.feature_names)
df['species'] = iris.target

# 2단계: 데이터 확인 (Data Table 위젯과 동일)
print(df.head(10))  # 처음 10행 출력

# 3단계: 산점도 그리기 (Scatter Plot 위젯과 동일)
colors = ['red', 'green', 'blue']
for species_id in [0, 1, 2]:
    subset = df[df['species'] == species_id]
    plt.scatter(subset['petal length (cm)'],
                subset['petal width (cm)'],
                c=colors[species_id],
                label=iris.target_names[species_id])

plt.xlabel('Petal Length (cm)')
plt.ylabel('Petal Width (cm)')
plt.legend()
plt.title('Iris Scatter Plot')
plt.show()

    # Chapter 04 - Iris 데이터 불러오고 확인하기
# (오렌지3 워크플로를 파이썬으로 표현한 버전)

import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris

# Iris 데이터셋 불러오기
iris = load_iris()
df = pd.DataFrame(iris.data, columns=iris.feature_names)
df['species'] = pd.Categorical.from_codes(iris.target, iris.target_names)

# 데이터 기본 정보 확인
print("=== 데이터 크기 ===")
print(f"행: {df.shape[0]}개, 열: {df.shape[1]}개")

print("\n=== 처음 5행 ===")
print(df.head())

print("\n=== 종류별 개수 ===")
print(df['species'].value_counts())

# 산점도 시각화
colors = {'setosa': 'red', 'versicolor': 'green', 'virginica': 'blue'}
for species, color in colors.items():
    subset = df[df['species'] == species]
    plt.scatter(subset['petal length (cm)'],
                subset['petal width (cm)'],
                c=color, label=species, alpha=0.7)

plt.xlabel('Petal Length (cm)')
plt.ylabel('Petal Width (cm)')
plt.title('Iris Dataset - Scatter Plot')
plt.legend()
plt.tight_layout()
plt.show()

    ⚠️ 자주 하는 실수¶

    실수 1: 위젯을 연결하지 않고 더블클릭부터 하는 경우

    Data Table이나 Scatter Plot 위젯을 캔버스에 올려놓은 뒤, 연결선을 만들기 전에 더블클릭하면 빈 화면이 나옵니다. 반드시 Datasets 위젯과 연결선을 만든 뒤에 확인 창을 열어야 데이터가 표시됩니다.

    실수 2: 연결 방향을 반대로 하는 경우

    오렌지3에서 데이터는 항상 왼쪽 → 오른쪽 방향으로 흐릅니다. Datasets에서 Data Table 방향으로 선을 연결해야 합니다. 반대로 연결하면 "incompatible channels"라는 오류 메시지가 뜹니다.

    실수 3: Datasets에서 Send 버튼을 누르지 않는 경우

    Datasets 위젯에서 iris를 선택한 뒤, 반드시 "Send" 버튼을 눌러야 데이터가 다음 위젯으로 전달됩니다. Send를 누르지 않으면 Data Table이 비어 있는 상태로 보입니다.

    실수 4: 설치 경로에 한글이 포함된 경우

    오렌지3를 설치할 때 경로에 한글(예: C:\사용자\바탕화면)이 포함되면 실행 오류가 발생합니다. 설치 경로는 반드시 영문으로만 구성된 기본 경로를 사용하세요.

    실수 5: 위젯 창을 닫지 않고 계속 쌓아두는 경우

    위젯을 더블클릭할 때마다 새 창이 열립니다. 창이 너무 많이 열리면 화면이 복잡해지고 컴퓨터가 느려질 수 있습니다. 확인이 끝난 창은 X 버튼으로 닫아 두세요.
