    챕터 12: 프로젝트 시각화 - 데이터로 이야기 만들기¶

    🎯 이 장에서 배우는 것¶

    • 전처리된 데이터를 2가지 이상의 시각화 방법으로 표현할 수 있다.
    • 시각화 결과에서 패턴이나 경향성을 발견하여 인사이트를 도출할 수 있다.
    • 같은 데이터도 관점에 따라 다르게 해석될 수 있음을 이해하고 설명할 수 있다.

    💡 왜 이걸 배우나요?¶

    숫자만 가득한 표를 보면 어떤 기분이 드나요? 아마 무엇을 읽어야 할지, 어디서 시작해야 할지 막막할 것입니다. 반면 같은 데이터라도 그래프로 표현하면 순식간에 "아, 이런 경향이 있구나!"라는 걸 느낄 수 있습니다.

    데이터 시각화는 숫자를 이야기로 바꾸는 작업입니다. 뉴스 기사에서 "올해 기온이 역대 최고를 기록했다"고 말할 때, 단순히 숫자를 나열하는 것보다 기온 변화 그래프 하나가 훨씬 강렬하게 메시지를 전달합니다.

    이번 챕터에서는 여러분이 직접 수집하고 전처리한 데이터를 오렌지3(Orange3)로 시각화하면서, 데이터 속에 숨겨진 패턴과 이야기를 발견하는 경험을 합니다. 데이터 분석의 꽃이라 할 수 있는 시각화를 직접 만들어봅시다!

    📚 핵심 개념¶

    개념 1: 시각화란 무엇인가 - 숫자를 그림으로¶

    비유로 시작

    지도를 생각해보세요. 서울에서 부산까지의 거리를 "약 325km"라고 말하는 것과, 지도 위에 두 도시를 표시하고 선으로 연결하는 것은 전달하는 정보가 같습니다. 그런데 지도를 보면 방향, 경유지, 주변 도시와의 관계까지 한눈에 파악됩니다. 데이터 시각화도 마찬가지입니다. 숫자 데이터를 '그림 언어'로 번역하는 것이죠.

    정확한 정의

    데이터 시각화(Data Visualization)란 데이터를 차트, 그래프, 지도 등 시각적 형태로 표현하여 데이터 속 패턴, 추세, 관계를 직관적으로 이해할 수 있게 만드는 과정입니다.

    예시로 확인

    학급 30명의 수학 점수 데이터가 있다고 가정합시다. - 숫자 그대로: 75, 82, 91, 68, 77, 85, 90, 72, 88, 65, ... - 시각화 후: 히스토그램으로 표현하면 점수가 80~90점대에 가장 많이 몰려 있고, 60점대가 가장 적다는 것을 0.5초 만에 파악 가능

    개념 2: 차트의 종류 - 목적에 맞는 도구 선택¶

    비유로 시작

    요리 도구를 생각해보세요. 국을 끓일 때 냄비를 쓰고, 고기를 구울 때 프라이팬을 씁니다. 둘 다 요리 도구지만 목적이 다릅니다. 차트도 마찬가지입니다. 보여주고 싶은 것이 무엇인지에 따라 알맞은 차트가 따로 있습니다.

    정확한 정의 및 주요 차트 유형

    graph TD A[내가 보여주고 싶은 것은?] --> B[비율/구성] A --> C[비교] A --> D[변화/추세] A --> E[관계/상관] B --> F[파이 차트 🥧<br/>도넛 차트] C --> G[막대 그래프 📊<br/>Bar Chart] D --> H[선 그래프 📈<br/>Line Chart] E --> I[산점도 🔵<br/>Scatter Plot]

    예시로 확인

    • 막대 그래프: "월별 강수량을 비교하고 싶다" → 각 월의 강수량 높이를 막대로 비교
    • 선 그래프: "1년간 기온 변화를 보고 싶다" → 시간의 흐름에 따른 연속적 변화
    • 산점도: "키와 몸무게의 관계가 있을까?" → 두 변수 사이의 상관관계 확인
    • 파이 차트: "좋아하는 과목 비율을 보고 싶다" → 전체 중 각 항목의 비중

    개념 3: 인사이트 도출 - 그래프에서 이야기 읽기¶

    비유로 시작

    형사가 범죄 현장의 단서를 보고 사건을 재구성하듯, 데이터 분석가는 그래프의 모양을 보고 이야기를 만들어냅니다. 그래프의 뾰족한 부분, 갑자기 꺾이는 부분, 두 데이터가 함께 움직이는 부분 - 이 모든 것이 단서입니다.

    정확한 정의

    인사이트(Insight)란 데이터 시각화를 통해 발견한 의미 있는 패턴, 경향, 이상값, 또는 예상치 못한 발견을 말합니다. 단순히 "A가 B보다 크다"는 사실 묘사가 아니라, "왜 그럴까?", "이것이 의미하는 바는 무엇인가?"까지 생각하는 것이 진짜 인사이트입니다.

    인사이트를 찾는 3가지 질문

    생각해보기 📌

    그래프를 볼 때 이 세 가지를 스스로에게 물어보세요.

    1. "가장 높은/낮은 부분은 어디인가?" → 극값(최대, 최소) 찾기
    2. "전체적인 흐름은 어떤가?" → 증가, 감소, 유지, 반복 패턴 찾기
    3. "예상과 다른 부분이 있는가?" → 이상값(Outlier)이나 반전 찾기

    예시로 확인

    편의점 음료 판매량 그래프를 보니 여름(7~8월)에 급증하고, 겨울(12~1월)에 급감합니다. - 사실 묘사: "7월 판매량이 12월보다 3배 많다." - 인사이트: "음료 수요는 기온과 강한 상관관계가 있다. 따라서 여름철 재고를 더 확보해야 한다."

    개념 4: 다양한 해석 가능성 - 같은 그래프, 다른 이야기¶

    비유로 시작

    같은 영화를 보고도 어떤 사람은 "슬픈 이별 영화"라 하고, 다른 사람은 "성장 이야기"라고 합니다. 데이터도 마찬가지입니다. 같은 그래프를 보고도 보는 사람의 관점, 배경지식, 목적에 따라 전혀 다른 이야기가 나올 수 있습니다.

    정확한 정의

    데이터 시각화에서 다양한 해석 가능성이란, 동일한 데이터나 차트에서 관찰자의 관점에 따라 서로 다른 의미와 결론을 도출할 수 있다는 개념입니다. 이것은 데이터 분석의 한계가 아니라, 데이터를 비판적으로 읽어야 한다는 중요한 교훈입니다.

    예시로 확인

    아래 상황을 생각해봅시다. "A 학교의 평균 성적이 매년 3점씩 올랐다."

    graph LR A[같은 데이터] --> B[교장 선생님의 관점] A --> C[학생의 관점] A --> D[교육 연구자의 관점] B --> E[우리 학교 교육이<br/>효과적이다! 🎉] C --> F[공부가 점점<br/>어려워지고 있다 😅] D --> G[시험 문제가<br/>쉬워진 건 아닐까? 🤔]

    알아보기 💡

    데이터를 해석할 때 "이 그래프를 만든 사람은 무엇을 강조하고 싶었을까?"를 함께 생각하는 것이 중요합니다. 같은 데이터라도 Y축의 범위를 조절하거나, 특정 기간만 선택하는 것만으로도 완전히 다른 인상을 줄 수 있습니다.

    🔨 따라하기¶

    이제 오렌지3를 활용해서 직접 데이터를 시각화해봅시다. 아래 실습은 여러분이 이전 챕터에서 전처리한 데이터 파일을 사용합니다. (예제용으로 '학급 성적 데이터'를 사용합니다.)

    Step 1: 오렌지3 실행 및 데이터 불러오기¶

    1. 오렌지3를 실행합니다.
    2. 새 워크플로우(New Workflow)를 시작합니다.
    3. 왼쪽 위젯 패널에서 Data → File 위젯을 캔버스로 드래그합니다.
    4. File 위젯을 더블클릭하여 전처리된 CSV 파일을 불러옵니다.
    5. 하단 상태 표시줄에서 몇 개의 행(row)과 열(column)이 로드되었는지 확인합니다.

    생각해보기 📌

    데이터를 불러온 후, 컬럼(열) 이름이 올바른지, 숫자 데이터가 숫자 타입으로 인식되었는지 꼭 확인하세요. Data Table 위젯을 연결해서 데이터를 눈으로 직접 확인하는 습관을 들이세요!

    Step 2: 첫 번째 시각화 - 막대 그래프 만들기¶

    1. 위젯 패널에서 Visualize → Bar Chart 를 캔버스로 드래그합니다.
    2. File 위젯의 출력 포트(오른쪽 점)와 Bar Chart의 입력 포트(왼쪽 점)를 연결합니다.
    3. Bar Chart 위젯을 더블클릭하여 엽니다.
    4. 설정 창에서:
    5. Group by: 비교하고 싶은 카테고리 컬럼 선택 (예: '반')
    6. Y-axis: 측정하려는 수치 컬럼 선택 (예: '수학 점수')
    7. Aggregation: Mean(평균) 선택
    8. 그래프가 생성되면 각 막대의 높이를 비교해봅니다.

    오렌지3 워크플로우 구성 예시

    graph LR A[📁 File\n데이터 불러오기] --> B[📊 Bar Chart\n막대 그래프] A --> C[📋 Data Table\n데이터 확인]

    Step 3: 두 번째 시각화 - 산점도 만들기¶

    1. 위젯 패널에서 Visualize → Scatter Plot 을 캔버스로 드래그합니다.
    2. File 위젯과 Scatter Plot을 연결합니다.
    3. Scatter Plot 위젯을 더블클릭하여 엽니다.
    4. 설정 창에서:
    5. X-axis: 첫 번째 수치 컬럼 선택 (예: '공부 시간')
    6. Y-axis: 두 번째 수치 컬럼 선택 (예: '수학 점수')
    7. Color: 카테고리 컬럼으로 색상 구분 (예: '반')
    8. 점들의 분포를 보면서 두 변수 사이에 관계가 있는지 관찰합니다.

    알아보기 💡

    산점도에서 점들이 왼쪽 아래에서 오른쪽 위로 모여 있으면 양의 상관관계 (한 값이 커질수록 다른 값도 커짐), 왼쪽 위에서 오른쪽 아래로 모여 있으면 음의 상관관계 (한 값이 커질수록 다른 값은 작아짐), 점들이 흩어져 있으면 상관관계 없음을 의미합니다.

    Step 4: 세 번째 시각화 - 분포 확인하기¶

    1. 위젯 패널에서 Visualize → Distributions 을 캔버스로 드래그합니다.
    2. File 위젯과 Distributions을 연결합니다.
    3. Distributions 위젯을 더블클릭합니다.
    4. 확인하고 싶은 수치 컬럼을 선택합니다 (예: '수학 점수').
    5. 히스토그램의 모양을 관찰합니다:
    6. 종 모양(정규분포)인가요?
    7. 한쪽으로 치우쳐 있나요?

    📝 전체 코드¶

    오렌지3는 주로 GUI(그래픽 인터페이스) 도구이지만, 파이썬 스크립트 위젯을 활용하면 더 정교한 시각화도 가능합니다. 아래는 오렌지3의 Python Script 위젯에서 실행할 수 있는 코드입니다.

    # 오렌지3 Python Script 위젯에서 실행
# 입력: in_data (File 위젯에서 연결된 데이터)

import matplotlib.pyplot as plt
import numpy as np

# 오렌지3 데이터를 pandas DataFrame으로 변환
import pandas as pd
df = pd.DataFrame(
    [list(row) for row in in_data],
    columns=[attr.name for attr in in_data.domain.attributes]
)

# --- 시각화 1: 막대 그래프 ---
fig, axes = plt.subplots(1, 2, figsize=(12, 5))

# 컬럼 이름은 여러분의 데이터에 맞게 수정하세요
# 예: '반'별 '수학 점수' 평균
if '반' in df.columns and '수학점수' in df.columns:
    group_means = df.groupby('반')['수학점수'].mean()
    axes[0].bar(group_means.index, group_means.values, color='steelblue')
    axes[0].set_title('반별 평균 수학 점수', fontsize=14)
    axes[0].set_xlabel('반')
    axes[0].set_ylabel('평균 점수')
    axes[0].grid(axis='y', alpha=0.3)

# --- 시각화 2: 산점도 ---
if '공부시간' in df.columns and '수학점수' in df.columns:
    axes[1].scatter(df['공부시간'], df['수학점수'],
                    alpha=0.6, color='coral', s=60)
    axes[1].set_title('공부 시간 vs 수학 점수', fontsize=14)
    axes[1].set_xlabel('공부 시간 (시간/주)')
    axes[1].set_ylabel('수학 점수')
    axes[1].grid(alpha=0.3)

plt.tight_layout()
plt.savefig('my_visualization.png', dpi=150, bbox_inches='tight')
plt.show()

print("시각화 완료! 'my_visualization.png'로 저장되었습니다.")

    알아보기 💡

    코드에서 '반', '수학점수', '공부시간' 부분은 여러분의 데이터 컬럼 이름으로 바꿔야 합니다. 컬럼 이름이 정확히 일치해야 실행됩니다!

    ⚠️ 자주 하는 실수¶

    실수 1: 모든 데이터에 같은 차트 사용하기

    "막대 그래프가 쉬우니까 다 막대 그래프로 만들면 되겠지!"라고 생각하는 경우가 많습니다. 하지만 시간에 따른 변화를 막대 그래프로 그리면 흐름이 잘 보이지 않고, 두 변수의 상관관계를 파이 차트로는 아예 표현할 수 없습니다. 항상 "내가 보여주고 싶은 것이 무엇인가?"를 먼저 생각하고 차트를 선택하세요.

    실수 2: 그래프 제목과 축 이름 생략하기

    그래프를 만들었는데 제목이 없거나 축에 단위가 없으면, 나중에 보는 사람(나 자신 포함!)이 무엇을 나타내는지 알 수 없습니다. 모든 그래프에는 반드시 제목, X축 이름, Y축 이름(단위 포함)을 적어야 합니다.

    예를 들어 Y축에 그냥 "점수"라고 하지 말고, "수학 점수 (100점 만점)"처럼 구체적으로 적습니다.

    실수 3: 상관관계를 인과관계로 착각하기

    산점도에서 공부 시간과 성적이 함께 올라가는 패턴을 발견했을 때, "공부를 많이 하면 성적이 오른다!"라고 결론짓는 것은 성급합니다. 상관관계는 두 값이 함께 변한다는 것이지, 하나가 다른 하나의 원인이라는 것을 증명하지 않습니다. "관련이 있는 것 같다"라고 표현하고, 왜 그럴지 추론하는 것이 올바른 방법입니다.

    실수 4: 이상값(Outlier)을 무시하거나 바로 삭제하기

    그래프에서 혼자 동떨어진 점(이상값)을 발견했을 때 "저건 오류니까 지우면 되겠다"라고 생각할 수 있습니다. 하지만 이상값은 오류일 수도 있지만, 가장 흥미로운 발견일 수도 있습니다. 먼저 왜 그 값이 튀는지 조사해보세요!
