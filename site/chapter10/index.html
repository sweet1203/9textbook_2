    Chapter 10. 텍스트 데이터 - 글에서 패턴 찾기¶

    🎯 이 장에서 배우는 것¶

    • 텍스트 데이터의 특성을 이해하고, 토큰화와 불용어 제거의 의미를 설명할 수 있다.
    • 오렌지3의 Corpus, Preprocess Text, Word Cloud 위젯으로 텍스트를 시각화할 수 있다.
    • 워드클라우드 결과를 해석하여 텍스트 속 주요 키워드와 의미를 도출할 수 있다.
    • 파이썬 코드로 한국어 텍스트를 분석하는 기본 흐름을 이해할 수 있다.

    💡 왜 이걸 배우나요?¶

    좋아하는 아이돌의 노래 가사를 떠올려 보세요. 그 노래에서 가장 많이 등장하는 단어는 무엇일까요? "사랑"일까요, "꿈"일까요, 아니면 "너"일까요?

    이런 궁금증을 해결하는 방법이 바로 텍스트 분석입니다. 텍스트 분석은 글 속에 숨어 있는 패턴을 컴퓨터가 찾아내는 기술입니다. 뉴스 기사, 소설, SNS 댓글, 설문 응답 등 세상에는 숫자보다 글로 된 데이터가 훨씬 많습니다. 이 글 데이터를 분석할 수 있다면, 사람들이 무엇에 관심을 갖는지, 어떤 감정을 느끼는지, 어떤 주제가 중요한지를 파악할 수 있습니다.

    이번 챕터에서는 텍스트를 시각적으로 표현하는 워드클라우드(Word Cloud) 를 만들어보면서, 글 속에서 패턴을 찾는 첫걸음을 내딛겠습니다.

    💬 생각해보기: 신문 기사 하나에는 평균 600~800개의 단어가 있습니다. 이걸 사람이 직접 세려면 얼마나 걸릴까요? 컴퓨터는 0.01초면 됩니다!

    📚 핵심 개념¶

    개념 1: 텍스트 데이터란 무엇인가?¶

    비유로 시작 📖

    숫자 데이터는 이미 잘 정리된 서랍장 같습니다. 1번 서랍에 키, 2번 서랍에 몸무게, 딱딱 정해진 자리가 있죠. 반면 텍스트 데이터는 마구 쌓인 편지 더미 같습니다. 내용은 풍부하지만, 컴퓨터가 바로 읽기엔 정리가 필요합니다.

    정확한 정의

    텍스트 데이터(Text Data)는 글자와 단어로 이루어진 비정형 데이터입니다. 숫자 데이터와 달리 구조가 정해져 있지 않아서, 컴퓨터가 분석하려면 특별한 전처리 과정이 필요합니다.

    graph LR A[📝 원본 텍스트\n'나는 오늘 학교에 갔다'] --> B[전처리] B --> C[🔢 컴퓨터가 분석 가능한 형태] style A fill:#FFE4B5 style B fill:#87CEEB style C fill:#90EE90

    예시로 확인

    • 정형 데이터(숫자): 키=170, 몸무게=65, 나이=17
    • 비정형 데이터(텍스트): "오늘 학교에서 친구들과 점심을 먹었는데 정말 맛있었어!"

    두 번째 문장에서 컴퓨터가 "맛있었어"라는 감정을 이해하려면, 먼저 문장을 단어로 쪼개고 의미를 파악해야 합니다.

    개념 2: 토큰화 - 문장을 단어로 쪼개기¶

    비유로 시작 ✂️

    레고 블록을 상상해 보세요. 완성된 레고 작품 전체를 분석하기는 어렵지만, 블록 하나하나로 분리하면 어떤 색이 몇 개인지 쉽게 셀 수 있습니다. 토큰화는 문장이라는 완성된 작품을 단어 블록으로 분리하는 작업입니다.

    정확한 정의

    토큰화(Tokenization) 는 텍스트를 분석 가능한 최소 단위인 토큰(Token) 으로 분리하는 과정입니다. 보통 단어 단위로 나누지만, 필요에 따라 문장이나 글자 단위로도 나눌 수 있습니다.

    graph TD A["원본 문장\n'나는 학교에서 공부를 열심히 했다'"] --> B[토큰화] B --> C["'나는'"] B --> D["'학교에서'"] B --> E["'공부를'"] B --> F["'열심히'"] B --> G["'했다'"] style A fill:#FFE4B5 style B fill:#87CEEB style C fill:#98FB98 style D fill:#98FB98 style E fill:#98FB98 style F fill:#98FB98 style G fill:#98FB98

    예시로 확인

    영어는 띄어쓰기로 나누면 비교적 쉽게 토큰화됩니다. - "I love Python" → ["I", "love", "Python"]

    한국어는 조금 더 복잡합니다. "학교에서"는 "학교" + "에서(조사)"로 나눠야 합니다. 이처럼 한국어는 형태소 단위 분석이 필요합니다.

    💬 알아보기: 형태소란 의미를 가진 가장 작은 언어 단위입니다. "학교에서"는 명사 "학교" + 조사 "에서"로 이루어진 형태소의 결합입니다.

    개념 3: 불용어 제거 - 중요하지 않은 단어 걸러내기¶

    비유로 시작 🧹

    금을 캐는 사람을 상상해 보세요. 강바닥의 모래를 체로 걸러서 금 조각만 남깁니다. 불용어 제거도 마찬가지입니다. 텍스트에서 의미 없이 자주 등장하는 단어를 걸러내고, 진짜 중요한 단어만 남기는 작업입니다.

    정확한 정의

    불용어(Stop Words) 는 텍스트 분석에서 큰 의미를 갖지 않는, 자주 등장하는 단어들입니다. 한국어의 경우 "은", "는", "이", "가", "을", "를", "의", "에서" 같은 조사와 "그리고", "하지만", "그런데" 같은 접속사가 이에 해당합니다.

    graph LR A["토큰 목록\n나는, 오늘, 은, 학교에, 갔다, 그리고, 밥을, 먹었다"] --> B[불용어 제거\n은 그리고 를 은는이가...] B --> C["핵심 단어\n오늘, 학교, 밥, 먹었다"] style A fill:#FFE4B5 style B fill:#FF6B6B style C fill:#90EE90

    예시로 확인

    • 제거 전: 나는, 오늘, 은, 학교에, 를, 갔다, 그리고, 점심을, 먹었다
    • 제거 후: 오늘, 학교, 갔다, 점심, 먹었다

    불용어를 제거하면 핵심 키워드만 남아서 텍스트의 주제가 훨씬 선명하게 보입니다.

    개념 4: 워드클라우드 - 단어 빈도를 시각화하기¶

    비유로 시작 🎨

    사진에서 중요한 피사체는 크고 선명하게, 배경은 흐릿하고 작게 보이죠. 워드클라우드도 똑같습니다. 자주 등장하는 단어는 크게, 가끔 나오는 단어는 작게 표시해서 텍스트의 핵심을 한눈에 보여줍니다.

    정확한 정의

    워드클라우드(Word Cloud) 는 텍스트에서 각 단어의 등장 빈도를 시각화한 그래프입니다. 단어가 많이 등장할수록 글자 크기가 커지고, 적게 등장할수록 작아집니다. 색상과 배치는 무작위로 정해지지만, 크기는 항상 빈도에 비례합니다.

    graph TD A[텍스트 수집] --> B[토큰화] B --> C[불용어 제거] C --> D[단어 빈도 계산] D --> E[워드클라우드 생성] style A fill:#FFE4B5 style B fill:#87CEEB style C fill:#DDA0DD style D fill:#F0E68C style E fill:#90EE90

    예시로 확인

    뉴스 기사 100개를 분석했더니 "기후", "탄소", "환경"이 가장 많이 나왔다면, 워드클라우드에서 이 단어들이 가장 크게 표시됩니다. 한눈에 "이 뉴스들은 환경 문제를 다루고 있구나!"라고 알 수 있습니다.

    🔨 따라하기¶

    준비: 오렌지3 텍스트 애드온 설치 확인¶

    오렌지3에서 텍스트 분석을 하려면 Text 애드온이 설치되어 있어야 합니다.

    설치 확인 방법: 오렌지3 실행 → 상단 메뉴 Options → Add-ons → 목록에서 Orange3-Text 확인 → 없으면 체크 후 OK 클릭

    Step 1: 분석할 텍스트 파일 준비하기¶

    실습에 사용할 텍스트 파일을 만들겠습니다. 메모장(Windows) 또는 텍스트 편집기를 열고 아래 내용을 입력한 후 news_sample.txt 로 저장합니다. 인코딩은 UTF-8로 설정하세요.

    오늘 환경부는 기후변화 대응을 위한 새로운 정책을 발표했다.
탄소 배출을 줄이기 위해 전기차 보급을 확대하고 재생에너지 투자를 늘리겠다고 밝혔다.
기후변화는 전 세계적인 문제로 탄소 중립 실현이 시급하다.
환경 전문가들은 기후 위기 대응을 위해 시민들의 참여가 중요하다고 강조했다.
재생에너지와 전기차는 탄소 배출 감소에 핵심적인 역할을 한다.
정부는 2030년까지 탄소 배출량을 40% 줄이겠다는 목표를 세웠다.
환경 단체들은 더 강력한 기후 정책을 요구하고 있다.
전기차 보급률을 높이면 대기 오염도 줄일 수 있다고 전문가들은 말했다.

    ⚠️ 주의: 파일을 저장할 때 반드시 인코딩을 UTF-8로 선택해야 한글이 깨지지 않습니다!

    Step 2: 오렌지3에서 텍스트 불러오기 (Corpus 위젯)¶

    오렌지3를 실행하고 새 워크플로를 시작합니다.

    ① Corpus 위젯 추가 - 왼쪽 위젯 패널에서 Text Mining 카테고리를 찾습니다. - Corpus 위젯을 캔버스로 드래그합니다.

    ② 파일 불러오기 - Corpus 위젯을 더블클릭합니다. - Browse 버튼을 클릭하여 방금 저장한 news_sample.txt를 선택합니다. - 파일이 정상적으로 불러와지면 오른쪽에 텍스트 목록이 표시됩니다.

    💬 알아보기: Corpus는 '텍스트 모음'을 뜻하는 언어학 용어입니다. 오렌지3의 Corpus 위젯은 다양한 형식의 텍스트 파일을 불러올 수 있습니다.

    Step 3: 텍스트 전처리하기 (Preprocess Text 위젯)¶

    ① Preprocess Text 위젯 추가 - Text Mining 카테고리에서 Preprocess Text 위젯을 캔버스로 드래그합니다. - Corpus 위젯의 출력 포트 → Preprocess Text 위젯의 입력 포트를 연결합니다.

    ② 전처리 설정 Preprocess Text 위젯을 더블클릭하면 여러 옵션이 나타납니다.

    • Tokenize: Word 선택 (단어 단위 토큰화)
    • Normalize: Lowercase 체크 (영어 대소문자 통일, 한국어에는 큰 영향 없음)
    • Filter: Stop words 체크, 언어를 Korean 으로 설정

    💬 정리하기: 전처리 순서를 기억하세요! 토큰화 → 정규화 → 불용어 제거 순서로 진행됩니다. 이 순서를 바꾸면 결과가 달라질 수 있습니다.

    Step 4: 워드클라우드 생성하기 (Word Cloud 위젯)¶

    ① Word Cloud 위젯 추가 - Text Mining 카테고리에서 Word Cloud 위젯을 캔버스로 드래그합니다. - Preprocess Text 위젯의 출력 포트 → Word Cloud 위젯의 입력 포트를 연결합니다.

    ② 결과 확인 - Word Cloud 위젯을 더블클릭합니다. - 텍스트에서 자주 등장한 단어들이 크기별로 배치된 워드클라우드가 나타납니다. - "환경", "기후", "탄소", "전기차" 같은 단어들이 크게 표시되는지 확인하세요.

    ③ 전체 워크플로 확인

    graph LR A[📄 Corpus\nnews_sample.txt] --> B[⚙️ Preprocess Text\n토큰화 + 불용어제거] B --> C[☁️ Word Cloud\n시각화] style A fill:#FFE4B5 style B fill:#87CEEB style C fill:#90EE90

    Step 5: 결과 해석하기¶

    워드클라우드를 보며 다음 질문에 답해보세요.

    • 가장 크게 보이는 단어 3개는 무엇인가요? → 이 단어들이 텍스트의 핵심 주제입니다.

    • 예상보다 크게 나온 단어가 있나요? → 그 단어가 생각보다 자주 등장했다는 뜻입니다.

    • 불용어가 아직 남아 있나요? → 있다면 사용자 정의 불용어 목록에 추가할 수 있습니다.

    💬 생각해보기: 워드클라우드만으로 "이 뉴스들이 환경 문제에 긍정적인지, 부정적인지"를 알 수 있을까요? 알 수 없다면 그 이유는 무엇일까요?

    Step 6: 파이썬으로 텍스트 분석 맛보기¶

    오렌지3로 시각적 분석을 해봤으니, 파이썬 코드로는 어떻게 처리하는지 확인해보겠습니다. 직접 실행해보는 것이 목표입니다.

    # 필요한 라이브러리 설치 (터미널에서 한 번만 실행)
# pip install wordcloud matplotlib konlpy

from collections import Counter
import matplotlib.pyplot as plt
from wordcloud import WordCloud

# 분석할 텍스트
text = """
오늘 환경부는 기후변화 대응을 위한 새로운 정책을 발표했다.
탄소 배출을 줄이기 위해 전기차 보급을 확대하고 재생에너지 투자를 늘리겠다고 밝혔다.
기후변화는 전 세계적인 문제로 탄소 중립 실현이 시급하다.
환경 전문가들은 기후 위기 대응을 위해 시민들의 참여가 중요하다고 강조했다.
"""

# 간단한 토큰화 (띄어쓰기 기준)
tokens = text.split()

# 불용어 정의
stop_words = ['을', '를', '이', '가', '은', '는', '의', '에', '에서', 
              '으로', '로', '와', '과', '도', '만', '위한', '위해',
              '하고', '했다', '있다', '한다', '수', '더']

# 불용어 제거
filtered = [word for word in tokens if word not in stop_words]

# 단어 빈도 계산
word_count = Counter(filtered)
print("가장 많이 등장한 단어 TOP 5:")
for word, count in word_count.most_common(5):
    print(f"  {word}: {count}회")

# 워드클라우드 생성
wc = WordCloud(
    font_path='malgun.ttf',   # Windows 한글 폰트
    background_color='white',
    width=800,
    height=400
)
wc.generate_from_frequencies(word_count)

plt.figure(figsize=(10, 5))
plt.imshow(wc, interpolation='bilinear')
plt.axis('off')
plt.title('뉴스 기사 워드클라우드')
plt.show()

    ⚠️ Mac 사용자: font_path를 '/Library/Fonts/AppleGothic.ttf'로 변경하세요.

    실행 결과 예시: 

    가장 많이 등장한 단어 TOP 5:
  기후변화: 2회
  탄소: 2회
  환경: 2회
  대응: 2회
  전기차: 1회

    📝 전체 코드¶

    아래 코드는 텍스트 파일을 읽어서 워드클라우드까지 생성하는 완성 버전입니다.

    # ============================================
# 텍스트 분석 & 워드클라우드 생성
# Chapter 10 완성 코드
# ============================================

from collections import Counter
import matplotlib.pyplot as plt
from wordcloud import WordCloud

# 1. 텍스트 파일 읽기
with open('news_sample.txt', 'r', encoding='utf-8') as f:
    text = f.read()

# 2. 토큰화 (띄어쓰기 기준)
tokens = text.split()

# 3. 불용어 정의 및 제거
stop_words = {
    '을', '를', '이', '가', '은', '는', '의', '에', '에서',
    '으로', '로', '와', '과', '도', '만', '위한', '위해',
    '하고', '했다', '있다', '한다', '수', '더', '및', '등',
    '것', '때', '또한', '그리고', '하지만', '그러나'
}
filtered_tokens = [w for w in tokens if w not in stop_words]

# 4. 단어 빈도 계산
word_freq = Counter(filtered_tokens)

# 5. 결과 출력
print("=== 단어 빈도 TOP 10 ===")
for word, count in word_freq.most_common(10):
    bar = "█" * count
    print(f"{word:10s} {bar} ({count})")

# 6. 워드클라우드 생성 및 저장
wc = WordCloud(
    font_path='malgun.ttf',
    background_color='white',
    width=800,
    height=400,
    colormap='viridis'
)
wc.generate_from_frequencies(word_freq)

plt.figure(figsize=(12, 6))
plt.imshow(wc, interpolation='bilinear')
plt.axis('off')
plt.title('📰 뉴스 기사 워드클라우드', fontsize=16, fontproperties=...)
plt.tight_layout()
plt.savefig('wordcloud_result.png', dpi=150)
plt.show()
print("워드클라우드가 'wordcloud_result.png'로 저장되었습니다!")

    ⚠️ 자주 하는 실수¶

    실수 1: 한글 폰트 설정 누락 워드클라우드에서 한글이 □□□로 깨져 보이는 경우입니다. font_path에 시스템에 설치된 한글 폰트 경로를 반드시 지정해야 합니다. Windows는 malgun.ttf, Mac은 AppleGothic.ttf를 사용하세요.

    실수 2: 불용어 목록이 부족해서 의미 없는 단어가 크게 표시됨 처음 만든 불용어 목록으로는 모든 조사와 접속사를 제거하기 어렵습니다. 워드클라우드 결과를 보고 의미 없는 단어가 크게 표시되면, 해당 단어를 불용어 목록에 추가하는 반복 개선 과정이 필요합니다.

    실수 3: 파일 인코딩 오류 텍스트 파일을 저장할 때 UTF-8이 아닌 다른 인코딩(EUC-KR 등)으로 저장하면 UnicodeDecodeError가 발생합니다. 파일 저장 시 항상 인코딩을 확인하고, 코드에서 encoding='utf-8'을 명시하세요.

    실수 4: 오렌지3에서 위젯 연결 순서 혼동 오렌지3에서 위젯을 연결할 때 출력 포트 → 입력 포트 방향으로 연결해야 합니다. Corpus의 출력을 Preprocess Text의 입력에, Preprocess Text의 출력을 Word Cloud의 입력에 연결하는 순서를 지키세요.

    기본 문제

    Q1. 텍스트 전처리 과정을 올바른 순서로 나열하세요.

    • ㄱ. 불용어 제거
    • ㄴ. 원본 텍스트 수집
    • ㄷ. 단어 빈도 계산
    • ㄹ. 토큰화

    정답: ㄴ → ㄹ → ㄱ → ㄷ

    Q2. 다음 중 한국어 불용어에 해당하는 것을 모두 고르세요. - ① 환경 ② 를 ③ 기후 ④ 그리고 ⑤ 탄소 ⑥ 은

    정답: ② ④ ⑥ (조사와 접속사)

    Q3. 워드클라우드에서 단어가 크게 표시될수록 의미하는 것은?

    정답: 해당 단어가 텍스트에서 더 자주 등장(높은 빈도)한다는 의미입니다.

    응용 문제

    Q4. 워드클라우드의 한계점을 한 가지 설명하세요. (힌트: "좋다"와 "좋지 않다"를 생각해보세요)

    정답 예시: 단어의 빈도만 보여줄 뿐, 문맥이나 감정(긍정/부정)을 알 수 없습니다. "좋다"가 크게 표시되어도 "좋지 않다"는 부정적인 표현인지 워드클라우드만으로는 구분하기 어렵습니다.

    📌 핵심 개념 요약¶

    • 텍스트 데이터 = 글자와 단어로 이루어진 비정형 데이터, 전처리 필요
    • 토큰화 = 문장을 단어(토큰) 단위로 분리하는 작업
    • 불용어 제거 = 분석에 불필요한 조사, 접속사 등을 걸러내는 작업
    • 워드클라우드 = 단어 빈도를 글자 크기로 표현한 시각화 방법
    • 전처리 순서 = 수집 → 토큰화 → 불용어 제거 → 빈도 계산 → 시각화
