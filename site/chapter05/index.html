    Chapter 05. 데이터 다듬기 ① - 빈칸과 이상한 값 찾기¶

    🎯 이 장에서 배우는 것¶

    • 결측값(빈 데이터)과 이상값의 개념을 이해하고, 실제 데이터에서 찾아낼 수 있다.
    • 오렌지3의 Select Rows, Purge Domain 위젯으로 결측값을 처리할 수 있다.
    • pandas의 isnull(), dropna(), fillna() 함수로 결측값을 다룰 수 있다.
    • 데이터 전처리가 분석 결과의 신뢰성에 미치는 영향을 설명할 수 있다.

    💡 왜 이걸 배우나요?¶

    반 전체 수학 시험 성적 평균을 구해야 한다고 상상해 보세요. 그런데 세 명의 점수가 성적표에 아예 적혀 있지 않습니다. 그냥 무시하고 평균을 내면 어떻게 될까요? 실제보다 높거나 낮게 나올 수 있습니다. 또 한 학생의 점수가 '1500점'이라고 입력되어 있다면? 100점 만점 시험에서 1500점은 분명히 뭔가 잘못된 값입니다.

    실제 데이터 분석 현장에서도 똑같은 일이 벌어집니다. 병원 환자 기록에 나이가 비어 있거나, 쇼핑몰 판매 데이터에 가격이 '-5000원'으로 입력된 경우가 드물지 않습니다. 이런 결함 있는 데이터로 분석을 시작하면, 아무리 좋은 알고리즘을 써도 결과를 믿을 수 없습니다.

    데이터 과학자들은 실제 업무 시간의 60~80%를 데이터를 정리하는 데 쓴다고 말합니다. 그만큼 '데이터 다듬기(전처리)'는 분석의 핵심 기술입니다. 이 장에서는 그 첫 번째 관문, 빈칸(결측값)과 이상한 값(이상값)을 찾아내고 처리하는 방법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 결측값 (Missing Value)¶

    비유로 시작 — 퍼즐 조각이 빠진 퍼즐

    100조각짜리 퍼즐을 맞추는데 5조각이 없다고 해 봅시다. 완성된 그림을 정확히 보기가 어렵겠죠. 데이터에서 결측값은 바로 이 '빠진 퍼즐 조각'입니다.

    정확한 정의: 결측값(Missing Value)이란 데이터셋에서 어떤 이유로 인해 값이 기록되지 않아 비어 있는 항목을 말합니다. 설문 응답자가 특정 질문을 건너뛰거나, 센서 오류로 데이터가 수집되지 않거나, 입력 담당자가 실수로 빈칸으로 남겨두는 경우가 대표적입니다.

    예시로 확인: 아래는 학생 성적 데이터입니다.

    이름     수학    영어    과학
김민준   85      92      (빈칸)
이서연   78      (빈칸)  88
박지훈   91      76      95

    김민준의 과학 점수와 이서연의 영어 점수가 결측값입니다. 파이썬에서는 이 빈칸을 NaN(Not a Number)이라고 표시합니다.

    개념 2: 이상값 (Outlier)¶

    비유로 시작 — 반 친구들 중 키가 3미터인 학생

    우리 반 학생들의 평균 키를 구하는데, 한 학생의 키가 300cm로 입력되어 있습니다. 이 값 하나 때문에 평균이 크게 올라갑니다. 실제 사람의 키라기보다 입력 오류일 가능성이 높죠.

    정확한 정의: 이상값(Outlier)이란 다른 값들과 비교했을 때 비정상적으로 크거나 작아서 전체 분석을 왜곡할 수 있는 값입니다. 이상값에는 두 가지 종류가 있습니다.

    • 입력 오류로 생긴 이상값: 실수로 잘못 입력된 값 (예: 100점 만점 시험에 '1500점' 입력)
    • 실제로 존재하는 극단값: 진짜로 발생한 드문 값 (예: 특정 날 갑자기 폭등한 주가)

    두 종류는 모두 '이상값'으로 분류되지만, 처리 방법이 달라질 수 있습니다.

    예시로 확인:

    학생    체중(kg)
A       52
B       61
C       58
D       470    ← 이상값! (입력 오류 추정)
E       55

    D의 체중 470kg은 명백히 입력 실수입니다. 47.0kg을 잘못 입력했을 가능성이 높습니다.

    개념 3: 데이터 전처리가 중요한 이유¶

    flowchart LR A["🗂️ 원본 데이터\n(결측값·이상값 포함)"] --> B{"전처리 했나요?"} B -- "❌ 안 함" --> C["❌ 오염된 분석 결과\n신뢰 불가"] B -- "✅ 함" --> D["✅ 깨끗한 데이터"] --> E["✅ 신뢰할 수 있는\n분석 결과"]

    결측값이나 이상값을 그대로 두면 평균, 합계 등 기본 통계량이 틀어지고, 머신러닝 모델의 예측 정확도도 크게 낮아집니다. 전처리는 분석의 '기초 공사'입니다.

    개념 4: 결측값 처리의 세 가지 전략¶

    결측값을 발견했을 때 취할 수 있는 방법은 크게 세 가지입니다.

    ① 삭제 (Drop): 결측값이 있는 행 또는 열 전체를 제거합니다. - 언제 쓰나요? 결측값이 전체 데이터의 5% 미만으로 적을 때 - 주의사항: 데이터를 잃어버리는 단점이 있습니다.

    ② 대체 (Fill/Impute): 결측값을 다른 값으로 채웁니다. - 평균값으로 채우기: 수치형 데이터에 자주 사용 - 최빈값으로 채우기: 범주형 데이터에 자주 사용 - 앞뒤 값으로 채우기: 시간 순서가 있는 데이터에 사용

    ③ 그대로 두기: 일부 분석 방법은 결측값을 자체적으로 처리합니다. - 언제 쓰나요? 사용하는 알고리즘이 결측값을 지원할 때

    flowchart TD A["결측값 발견!"] --> B{결측값 비율은?} B -- "5% 미만" --> C["① 삭제 고려"] B -- "5% 이상" --> D{데이터 유형은?} D -- "수치형" --> E["② 평균값으로 대체"] D -- "범주형" --> F["② 최빈값으로 대체"] C --> G["✅ 깨끗한 데이터"] E --> G F --> G

    🔨 따라하기¶

    이제 직접 실습해 봅시다. 실습에 사용할 파일을 먼저 만들고, 오렌지3와 파이썬으로 각각 결측값을 찾아 처리합니다.

    Step 1: 실습 데이터 파일 만들기¶

    아래 내용을 메모장(윈도우) 또는 텍스트 편집기에 붙여넣고, students.csv라는 이름으로 저장하세요. (인코딩: UTF-8)

    이름,수학,영어,과학,체중

이서연,78,,88,61

    알아보기: 빈칸 확인
    김민준의 과학 점수, 이서연의 영어 점수, 정우성의 수학 점수가 비어 있습니다. 그리고 박지훈의 체중 470은 이상값입니다.

    Step 2: 오렌지3에서 데이터 불러오기¶

    ① File 위젯 추가 - 오렌지3를 실행합니다. - 왼쪽 위젯 패널에서 Data 탭 → File 위젯을 캔버스로 드래그합니다. - File 위젯을 더블클릭해서 열고, students.csv 파일을 선택합니다.

    ② Data Table로 확인 - Data 탭 → Data Table 위젯을 캔버스에 추가합니다. - File 위젯의 오른쪽 점과 Data Table의 왼쪽 점을 연결합니다. - Data Table을 더블클릭하면 데이터가 보입니다. 빈칸은 ? 또는 빈 셀로 표시됩니다.

    생각해보기: Data Table에서 결측값이 어떻게 표시되었나요? 오렌지3에서는 빈 칸을 어떤 기호로 나타내고 있나요?

    Step 3: 오렌지3 — Select Rows로 결측값 있는 행 필터링¶

    ① Select Rows 위젯 추가 - Data 탭 → Select Rows 위젯을 캔버스에 추가합니다. - File 위젯과 Select Rows 위젯을 연결합니다.

    ② 조건 설정 - Select Rows 위젯을 더블클릭하여 엽니다. - Add Condition 버튼을 클릭합니다. - 첫 번째 드롭다운에서 수학 선택 → 두 번째 드롭다운에서 is defined 선택합니다. - 같은 방식으로 영어, 과학 컬럼도 is defined 조건을 추가합니다. - Conditions must match: all 옵션을 선택합니다 (AND 조건).

    ③ 결과 확인 - Select Rows의 출력을 새 Data Table에 연결합니다. - 결측값이 있는 행(김민준, 이서연, 정우성)이 필터링되어 제외된 것을 확인합니다.

    flowchart LR A["📂 File\nstudents.csv"] --> B["🔍 Select Rows\n조건: 수학·영어·과학\n모두 is defined"] B --> C["📋 Data Table\n결측값 없는\n행만 표시"]

    Step 4: 오렌지3 — Purge Domain으로 정리하기¶

    결측값이 있는 행을 제거한 뒤에도, 해당 값들의 '흔적'이 도메인(데이터 구조)에 남아 있을 수 있습니다. Purge Domain 위젯이 이를 깔끔하게 정리합니다.

    • Data 탭 → Purge Domain 위젯을 캔버스에 추가합니다.
    • Select Rows → Purge Domain → Data Table 순서로 연결합니다.
    • Purge Domain을 열어 Remove unused values 옵션이 체크되어 있는지 확인합니다.

    정리하기: Select Rows는 원하지 않는 행을 거르는 위젯이고, Purge Domain은 거른 뒤 불필요한 흔적을 청소하는 위젯입니다.

    Step 5: 파이썬으로 같은 작업 해보기¶

    오렌지3에서 한 작업을 파이썬 pandas로도 해봅시다. 아래 코드를 복사해서 주피터 노트북 또는 구글 코랩에 붙여넣고 실행하세요.

    import pandas as pd

# 1. 데이터 불러오기
df = pd.read_csv('students.csv')
print("=== 원본 데이터 ===")
print(df)
print()

# 2. 결측값 현황 파악
print("=== 결측값 개수 (컬럼별) ===")
print(df.isnull().sum())
print()

# 3. 결측값이 있는 행 확인
print("=== 결측값이 있는 행 ===")
print(df[df.isnull().any(axis=1)])
print()

# 4. 결측값이 있는 행 제거
df_dropped = df.dropna()
print("=== 결측값 제거 후 ===")
print(df_dropped)
print()

# 5. 이상값 확인 (체중)
print("=== 체중 기초 통계 ===")
print(df['체중'].describe())

    Step 6: 파이썬으로 이상값 처리하기¶

    이상값인 박지훈의 체중 470kg을 처리해 봅시다.

    # 이상값 처리 방법 1: 해당 행 제거
df_no_outlier = df_dropped[df_dropped['체중'] < 200]
print("=== 이상값 제거 후 체중 평균 ===")
print(f"평균 체중: {df_no_outlier['체중'].mean():.1f} kg")

# 이상값 처리 방법 2: 평균값으로 대체
mean_weight = df[df['체중'] < 200]['체중'].mean()
df_filled = df.copy()
df_filled.loc[df_filled['체중'] >= 200, '체중'] = mean_weight
print()
print("=== 이상값을 평균으로 대체한 결과 ===")
print(df_filled['체중'])

    📝 전체 코드¶

    아래는 이번 장에서 배운 모든 내용을 담은 완성 코드입니다. 복사해서 바로 실행할 수 있습니다.

    import pandas as pd

# ─────────────────────────────────────
# 0. 실습 데이터 직접 생성 (CSV 파일 없을 때)

df = pd.read_csv(io.StringIO(raw_data))

# ─────────────────────────────────────

print("【결측값 현황】")

print(f"\n전체 결측값 수: {df.isnull().sum().sum()}개")

# ─────────────────────────────────────

# ─────────────────────────────────────
df_clean = df.dropna(subset=['수학', '영어', '과학'])
print("\n【결측값 제거 후 데이터】")
print(df_clean)

# ─────────────────────────────────────
# 3. 이상값 처리 - 제거
# ─────────────────────────────────────

    ⚠️ 자주 하는 실수¶

    실수 1: 결측값을 숫자 0으로 착각하기

    결측값(NaN)과 숫자 0은 다릅니다. 0은 '값이 있고, 그 값이 0'이라는 뜻입니다. NaN은 '값 자체가 없다'는 뜻입니다. 시험을 치르지 않은 것(NaN)과 0점을 받은 것(0)은 완전히 다릅니다!

    # 잘못된 방법: NaN을 0으로 채우면 평균이 낮아짐
df['수학'].fillna(0)   # ❌ 시험을 안 친 학생이 0점 처리됨

# 올바른 방법: 평균으로 채우기
df['수학'].fillna(df['수학'].mean())   # ✅

    실수 2: dropna() 후 인덱스가 초기화되지 않는 것을 모르기

    dropna()로 행을 제거하면 인덱스 번호에 빈 번호가 생깁니다. 나중에 반복문이나 인덱스 접근 시 오류가 날 수 있습니다.

    df_clean = df.dropna()
# 인덱스: 0, 2, 3, 5 (1, 4가 빠짐) ← 문제 발생 가능

# 올바른 방법: 인덱스 재설정
df_clean = df.dropna().reset_index(drop=True)
# 인덱스: 0, 1, 2, 3 ← 깔끔하게 정리

    실수 3: 이상값을 무조건 제거하려는 실수

    이상값이라고 해서 항상 제거하는 것이 옳은 것은 아닙니다. 예를 들어, 신용카드 사기 탐지에서 '이상한 거래 패턴'이 바로 우리가 찾고 싶은 값입니다. 이상값을 처리하기 전에 반드시 그 값이 왜 이상한지 먼저 파악해야 합니다.

    실수 4: 오렌지3에서 Select Rows 조건을 잘못 설정하기

    Select Rows에서 조건을 AND(모두 일치)로 설정해야 할 때 OR(하나라도 일치)로 설정하면, 의도와 반대 결과가 나옵니다. 조건을 설정한 뒤에는 반드시 결과 데이터 수를 확인하는 습관을 들이세요.

    도전 2 (심화): 이상값 자동 탐지

    통계학에서 IQR(사분위수 범위) 방법으로 이상값을 자동으로 탐지할 수 있습니다. 아래 코드를 실행하고, 어떤 원리인지 찾아보세요.

    Q1 = df['체중'].quantile(0.25)
Q3 = df['체중'].quantile(0.75)
IQR = Q3 - Q1

# IQR의 1.5배를 벗어나면 이상값으로 판단
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df['체중'] < lower) | (df['체중'] > upper)]
print("이상값으로 판단된 행:")
print(outliers)
