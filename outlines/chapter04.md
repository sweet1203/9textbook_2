# 오렌지3 첫 만남 - 나의 데이터 분석 도구

**Part 2**: [1권] 빅데이터와 도구 준비

---

## 학습 목표

- [ ] 오렌지3를 설치하고 기본 인터페이스의 구성 요소를 파악할 수 있다.
- [ ] 위젯을 캔버스에 배치하고 연결하여 간단한 워크플로를 만들 수 있다.
- [ ] 내장 데이터셋을 불러와 데이터 테이블로 확인하는 과정을 수행할 수 있다.

## 개요

레고 블록을 조립하듯 데이터 분석을 할 수 있다면? 오렌지3는 코딩 없이 위젯을 연결해 데이터를 분석하는 시각적 도구입니다. 설치 과정을 단계별로 따라하고, 캔버스·위젯 목록·상태창 등 인터페이스를 하나씩 탐색합니다. 내장 Iris 데이터셋을 불러와 Data Table 위젯으로 데이터를 눈으로 확인하는 첫 활동을 수행하고, 파이썬에서 같은 데이터를 불러오는 코드 화면도 함께 살펴봅니다. 확인 문제로 오렌지3 인터페이스 용어를 점검하고, 도전 문제로 '위젯 3개를 자유롭게 연결해보기'에 도전합니다.
