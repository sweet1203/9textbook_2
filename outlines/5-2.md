# 글자도 데이터다 — 텍스트 데이터 시각화

**Part 5**: Part 5. 이미지와 텍스트도 데이터다 — 비정형 데이터 시각화

---

## 학습 목표

- [ ] 텍스트 데이터의 특징과 워드클라우드의 의미를 설명할 수 있다.
- [ ] 오렌지3의 Corpus, Word Cloud 위젯으로 텍스트 데이터를 시각화할 수 있다.
- [ ] 워드클라우드 결과에서 핵심 키워드를 찾아 의미를 해석할 수 있다.

## 개요

생각해보기로 '윤동주 시에서 가장 많이 나오는 단어가 뭔지 세어본 적 있나요?'라며 텍스트 데이터 분석의 흥미로운 면을 소개합니다. 텍스트 데이터가 어떻게 분석되는지(단어 분리→빈도 계산→시각화) 흐름을 간단히 설명하고, 교과서 실습 데이터(윤동주 시 텍스트)를 활용해 Corpus 위젯으로 텍스트를 불러오고 Word Cloud 위젯으로 단어 빈도를 시각화합니다. 워드클라우드 결과를 보며 '윤동주 시의 핵심 주제는 무엇인가?'를 토론하는 활동으로 데이터 해석 능력을 키웁니다. 확인 문제로 워드클라우드 결과 해석하기, 도전 문제로 좋아하는 가사나 책의 일부를 텍스트 데이터로 만들어 워드클라우드를 생성해보기로 마무리합니다.
