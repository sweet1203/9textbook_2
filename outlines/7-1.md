# 보고서를 완성하라 — 구글 슬라이드로 분석 결과 정리하기

**Part 7**: Part 7. 나의 데이터 이야기를 완성하라 — 보고서와 발표

---

## 학습 목표

- [ ] 데이터 보고서의 기본 구성(주제→수집→전처리→시각화→분석→결론)을 이해하고 슬라이드를 완성할 수 있다.
- [ ] 오렌지3에서 만든 시각화 결과를 슬라이드에 삽입하고 설명을 추가할 수 있다.
- [ ] 결론 슬라이드에서 데이터 분석을 통해 발견한 문제와 해결 방안을 제안할 수 있다.

## 개요

생각해보기로 '열심히 분석한 결과를 아무도 이해 못 하면 어떡할까? 좋은 보고서가 분석만큼 중요한 이유'라며 보고서 완성의 필요성을 강조합니다. 데이터 보고서 6단계 구성 템플릿을 안내하고, 지금까지 구글 슬라이드에 기록해온 내용을 바탕으로 전체 보고서를 완성합니다. 오렌지3 시각화 결과를 이미지로 저장해 슬라이드에 삽입하고, 각 슬라이드에 핵심 인사이트를 2~3문장으로 간결하게 작성하는 연습을 합니다. 결론 슬라이드에서 '데이터로 발견한 안전사고 문제와 우리가 제안하는 해결 방안'을 정리합니다. 확인 문제로 보고서 구성 체크리스트 점검, 도전 문제로 발표 노트를 추가 작성해보기로 마무리합니다.
