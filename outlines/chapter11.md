# 프로젝트 시작! - 질문하고 데이터 모으기

**Part 5**: [2권] 프로젝트 - 나만의 데이터 이야기

---

## 학습 목표

- [ ] 데이터로 탐구할 수 있는 구체적인 문제(질문)를 스스로 설정할 수 있다.
- [ ] 공공데이터포털 등에서 주제에 맞는 데이터를 검색하고 수집할 수 있다.
- [ ] 수집한 데이터를 오렌지3에 불러와 전처리까지 완료할 수 있다.

## 개요

'궁금한 것을 데이터로 확인할 수 있다면?'이라는 질문에서 프로젝트가 시작됩니다. 좋은 데이터 탐구 질문의 조건(구체적, 데이터로 확인 가능, 관심 분야)을 배우고 자신만의 질문을 설정합니다. 공공데이터포털, 통계청 KOSIS 등에서 주제에 맞는 데이터를 직접 찾아 다운로드하고, 오렌지3에 불러와 앞서 배운 전처리 기법을 적용합니다. 확인 문제로 좋은 탐구 질문의 조건을 점검하고, 도전 문제로 '데이터 수집 과정에서 겪은 어려움과 해결 방법 기록하기'를 수행합니다.
