# 텍스트 데이터 - 글에서 패턴 찾기

**Part 4**: [2권] 데이터 시각화 - 그림으로 말하기

---

## 학습 목표

- [ ] 텍스트 데이터의 특성을 이해하고 전처리(토큰화, 불용어 제거) 과정을 설명할 수 있다.
- [ ] 오렌지3의 Corpus, Preprocess Text, Word Cloud 위젯으로 텍스트를 시각화할 수 있다.
- [ ] 워드클라우드 결과를 해석하여 텍스트에 담긴 주요 키워드와 의미를 도출할 수 있다.

## 개요

좋아하는 노래 가사에서 가장 많이 나오는 단어는 무엇일까? 이 질문으로 텍스트 분석의 세계에 들어갑니다. 텍스트를 컴퓨터가 분석하려면 단어 단위로 쪼개고(토큰화), '은/는/이/가' 같은 불필요한 단어를 제거하는(불용어 처리) 전처리가 필요합니다. 오렌지3에서 텍스트 파일을 불러와 Preprocess Text로 전처리한 뒤 Word Cloud로 시각화하는 실습을 진행합니다. 파이썬 KoNLPy 등의 텍스트 분석 코드 화면도 보여줍니다. 확인 문제로 텍스트 전처리 순서를 점검하고, 도전 문제로 '뉴스 기사 하나를 워드클라우드로 만들고 핵심 주제 추론하기'를 수행합니다.

## 예상 소요 시간

2시간
