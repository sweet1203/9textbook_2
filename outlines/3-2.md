# 데이터를 합치고 나누기 — 통합과 정규화

**Part 3**: Part 3. 데이터를 다듬어라 — 빅데이터 전처리

---

## 학습 목표

- [ ] 데이터 통합의 필요성과 공통 속성(키값)의 개념을 설명할 수 있다.
- [ ] 오렌지3의 Merge Data 위젯으로 두 데이터셋을 합칠 수 있다.
- [ ] Discretize 위젯으로 연속형 데이터를 구간으로 나눌 수 있다.

## 개요

생각해보기로 '학생 성적 데이터와 출석 데이터가 따로 있다면 어떻게 합칠 수 있을까?'라는 질문으로 데이터 통합의 필요성을 느끼게 합니다. 공통 속성(User_ID 등 키값)을 기준으로 두 데이터셋을 합치는 개념을 퍼즐 맞추기에 비유해 설명합니다. 교과서 실습 데이터(칼로리 데이터)를 활용해 Merge Data 위젯으로 데이터를 통합하고, Discretize 위젯으로 나이 데이터를 10대·20대·30대 등 구간으로 나누는 실습을 진행합니다. 확인 문제로 키값 찾기 연습, 도전 문제로 직접 수집한 설문 데이터에 Discretize 위젯을 적용해보기로 마무리합니다.
