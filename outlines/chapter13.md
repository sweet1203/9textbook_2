# 보고서 완성 - 나의 데이터 보고서

**Part 5**: [2권] 프로젝트 - 나만의 데이터 이야기

---

## 학습 목표

- [ ] 데이터 분석 과정(문제 설정→수집→전처리→시각화→인사이트)을 체계적으로 보고서에 정리할 수 있다.
- [ ] 시각화 자료를 효과적으로 배치하고 설명을 붙여 읽는 사람이 이해하기 쉬운 보고서를 작성할 수 있다.
- [ ] 분석 과정에서의 한계점과 추가 탐구 가능성을 보고서에 포함할 수 있다.

## 개요

지금까지의 분석 과정을 하나의 보고서로 엮어 완성합니다. 보고서 템플릿(제목, 탐구 질문, 데이터 출처, 전처리 과정, 시각화 결과, 인사이트, 한계점·느낀점)을 따라 단계별로 작성하며, 시각화 이미지를 보고서에 삽입하고 설명을 다는 연습을 합니다. '이 분석의 한계는 무엇인가?', '더 알고 싶은 것은?'이라는 질문에 답하며 보고서의 깊이를 더합니다. 확인 문제로 보고서 필수 항목을 점검하고, 도전 문제로 '보고서를 한 문장으로 요약하는 핵심 메시지 만들기'를 수행합니다.
