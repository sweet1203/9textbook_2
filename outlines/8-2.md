# 돌아보기 그리고 앞으로 — 성찰과 다음 여정

**Part 8**: Part 8. 마무리와 다음 여정 — 최종 점검과 성찰

---

## 학습 목표

- [ ] 이번 단원에서 배운 데이터 활용 전 과정(압축·암호화→수집→전처리→시각화→분석→보고)을 흐름도로 요약할 수 있다.
- [ ] 데이터 분석 과정에서 어렵거나 흥미로웠던 점을 구체적으로 성찰할 수 있다.
- [ ] 앞으로 데이터로 탐구하고 싶은 주제와 배우고 싶은 도구를 스스로 계획할 수 있다.

## 개요

생각해보기로 '처음엔 오렌지3가 뭔지도 몰랐는데, 이제는 결측치도 처리하고 워드클라우드도 만들고 보고서도 완성했다!'라며 8차시 동안의 성장을 함께 돌아봅니다. 전체 학습 과정을 한 장의 흐름도(압축·암호화 → 빅데이터 개념 → 수집 → 전처리 → 시각화 → 분석 → 보고서)로 정리하고, 각 단계에서 사용한 도구와 핵심 개념을 복습합니다. 구글 설문지로 만든 단원 성찰지(가장 흥미로웠던 활동, 가장 어려웠던 부분, 다음에 해보고 싶은 것)를 작성하며 메타인지를 키웁니다. 확인 문제로 전체 과정 순서 맞추기, 도전 문제로 '내가 데이터로 해결하고 싶은 사회 문제'를 자유롭게 적어보기로 마무리합니다.
