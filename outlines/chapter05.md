# 데이터 다듬기 ① - 빈칸과 이상한 값 찾기

**Part 3**: [1권] 데이터 다듬기 - 전처리의 기술

---

## 학습 목표

- [ ] 결측값(빈 데이터)과 이상값의 개념을 이해하고 실제 데이터에서 찾아낼 수 있다.
- [ ] 오렌지3의 Select Rows, Purge Domain 위젯으로 결측값을 처리할 수 있다.
- [ ] 데이터 전처리가 분석 결과의 신뢰성에 미치는 영향을 설명할 수 있다.

## 개요

시험 성적표에 한 과목 점수가 빠져있다면 평균을 어떻게 구할까? 이 질문으로 결측값 문제를 직관적으로 이해합니다. 오렌지3에 실습용 CSV 파일을 불러와 빈칸(결측값)과 비정상적으로 튀는 값(이상값)을 눈으로 확인하고, Select Rows 위젯으로 조건 필터링하여 문제 데이터를 처리하는 활동을 수행합니다. 파이썬 pandas로 같은 작업을 하는 코드 화면과 실행결과를 보여주며 비교합니다. 확인 문제로 결측값 처리 방법을 점검하고, 도전 문제로 '의도적으로 빈칸이 있는 데이터를 직접 정리해보기'를 수행합니다.
