# 이미지 데이터 - 사진도 데이터야!

**Part 4**: [2권] 데이터 시각화 - 그림으로 말하기

---

## 학습 목표

- [ ] 이미지가 컴퓨터에서 숫자(픽셀) 데이터로 저장되는 원리를 이해할 수 있다.
- [ ] 오렌지3 Image Viewer 위젯으로 이미지 데이터셋을 탐색하고 분류 결과를 시각화할 수 있다.
- [ ] 이미지 데이터 분석의 실생활 활용 사례를 설명할 수 있다.

## 개요

스마트폰으로 찍은 사진 한 장은 사실 수만 개의 숫자 묶음이라는 사실을 알고 있나요? 이미지가 픽셀 단위의 숫자 데이터로 구성되는 원리를 간단한 그림으로 이해합니다. 오렌지3에서 내장 이미지 데이터셋을 불러와 Image Viewer로 탐색하고, Image Embedding과 Scatter Plot을 연결해 비슷한 이미지끼리 모이는 시각화를 체험합니다. 의료 영상 분석, 자율주행 등 이미지 데이터 분석의 실생활 사례도 살펴봅니다. 확인 문제로 이미지 데이터 구조를 점검하고, 도전 문제로 '내 사진 5장을 오렌지3에 불러와 탐색해보기'를 수행합니다.
