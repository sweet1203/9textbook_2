# 사진도 데이터다 — 이미지 데이터 시각화

**Part 5**: Part 5. 이미지와 텍스트도 데이터다 — 비정형 데이터 시각화

---

## 학습 목표

- [ ] 비정형 데이터로서 이미지 데이터의 특징을 설명할 수 있다.
- [ ] 오렌지3의 Import Images, Image Viewer 위젯으로 이미지 데이터를 불러오고 시각화할 수 있다.
- [ ] 이미지 데이터 시각화의 실생활 활용 사례(의료영상, 자율주행 등)를 설명할 수 있다.

## 개요

생각해보기로 '인스타그램은 어떻게 내가 올린 사진이 음식인지 풍경인지 알아낼까?'라는 질문으로 이미지 데이터 분석의 신기함을 느끼게 합니다. 비정형 데이터(이미지·영상·텍스트)와 정형 데이터의 차이를 복습하고, 이미지 데이터가 어떻게 숫자(픽셀값)로 변환되는지 간단히 설명합니다. 교과서 실습 데이터(은하 및 축구 선수 이미지)를 활용해 Import Images 위젯으로 이미지를 불러오고 Image Viewer로 확인하는 워크플로우를 만들어봅니다. 확인 문제로 비정형 데이터 사례 분류하기, 도전 문제로 직접 찍은 사진을 오렌지3에 불러와 Image Viewer로 확인해보기로 마무리합니다.
