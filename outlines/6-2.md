# 데이터로 이야기하라 — 안전사고 데이터 시각화와 인사이트 도출

**Part 6**: Part 6. 데이터로 문제를 해결하라 — 협력적 창의·융합 프로젝트

---

## 학습 목표

- [ ] 안전사고 데이터를 목적에 맞는 시각화 방법(박스플롯, 산점도, 지도 등)으로 표현할 수 있다.
- [ ] 시각화 결과에서 패턴과 경향을 읽어 인사이트 문장을 작성할 수 있다.
- [ ] 사실(데이터가 보여주는 것)과 해석(내 생각)을 구분하여 분석 내용을 정리할 수 있다.

## 개요

생각해보기로 '같은 데이터도 어떤 그래프로 보여주느냐에 따라 전달되는 메시지가 달라진다'라며 시각화 선택의 중요성을 강조합니다. 모둠별로 전처리한 안전사고 데이터를 오렌지3에서 최소 2가지 이상의 시각화 방법으로 표현하고, 각 시각화에서 발견한 패턴을 '발견 → 해석 → 주장' 3단계로 정리하는 활동을 진행합니다. '사실과 해석 구분하기' 연습을 통해 데이터 기반 주장의 논리성을 높이고, 구글 슬라이드에 시각화 결과와 인사이트를 추가합니다. 확인 문제로 인사이트 문장 작성하기, 도전 문제로 '왜 이런 패턴이 나타날까?' 가설을 세우고 추가 데이터로 검증해보기로 마무리합니다.
