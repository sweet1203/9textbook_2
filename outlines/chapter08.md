# 데이터를 그림으로 ② - 지도와 시간 시각화

**Part 4**: [2권] 데이터 시각화 - 그림으로 말하기

---

## 학습 목표

- [ ] 지리 데이터를 지도 위에 시각화하는 방법을 이해하고 오렌지3 Geo Map 위젯을 활용할 수 있다.
- [ ] 시간에 따라 변화하는 데이터를 선 그래프(Line Plot)로 표현할 수 있다.
- [ ] 데이터의 성격에 맞는 시각화 유형을 스스로 선택하고 그 이유를 설명할 수 있다.

## 개요

우리 동네 편의점 분포를 지도 위에 점으로 찍으면 어떤 모습일까? 위치 정보가 포함된 데이터를 오렌지3 Geo Map 위젯으로 지도 위에 시각화하는 활동을 수행합니다. 이어서 시간 축이 있는 데이터를 선 그래프로 그려 시간에 따른 변화 추이를 읽어보고, 어떤 데이터에 어떤 시각화가 적합한지 스스로 판단하는 연습을 합니다. 파이썬 folium과 matplotlib으로 같은 시각화를 구현한 코드 화면을 제시합니다. 확인 문제로 시각화 유형 매칭을 점검하고, 도전 문제로 '내가 관심 있는 데이터에 가장 적합한 시각화 유형 제안서 작성'을 수행합니다.
