# 데이터를 그림으로 ① - 기본 차트 마스터

**Part 4**: [2권] 데이터 시각화 - 그림으로 말하기

---

## 학습 목표

- [ ] 박스플롯, 히스토그램, 산점도의 특징과 용도를 구분하여 설명할 수 있다.
- [ ] 오렌지3에서 Box Plot, Distributions, Scatter Plot 위젯을 사용하여 데이터를 시각화할 수 있다.
- [ ] 시각화 결과를 보고 데이터의 분포와 관계를 자신의 말로 해석할 수 있다.

## 개요

같은 숫자 데이터도 표로 보느냐 그래프로 보느냐에 따라 전혀 다른 이야기를 들려줍니다. 박스플롯으로 데이터의 퍼짐과 중앙값을 확인하고, 히스토그램으로 분포의 모양을 살펴보고, 산점도로 두 변수 사이의 관계를 탐색합니다. 오렌지3에서 각 위젯을 연결해 시각화하는 실습을 단계별로 진행하며, 파이썬 matplotlib 코드로 같은 차트를 그린 화면도 함께 제시합니다. 확인 문제로 차트 유형별 적합한 상황을 점검하고, 도전 문제로 '우리 반 키·발 사이즈 데이터를 산점도로 그려 관계 해석하기'를 수행합니다.
