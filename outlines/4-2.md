# 지도와 시간으로 보는 데이터 — 지리·시간 데이터 시각화

**Part 4**: Part 4. 데이터를 눈에 보이게 — 빅데이터 시각화

---

## 학습 목표

- [ ] 지리 데이터와 시간 데이터 시각화의 특징과 활용 사례를 설명할 수 있다.
- [ ] 오렌지3의 Geo Map 위젯으로 지리 데이터를 지도에 표현할 수 있다.
- [ ] Time Slice 위젯으로 시간 흐름에 따른 데이터 변화를 확인할 수 있다.

## 개요

생각해보기로 '전국 학교가 언제, 어디에 많이 생겼는지 한눈에 볼 수 있다면 어떨까?'라며 지리·시간 시각화의 흥미로운 가능성을 보여줍니다. 교과서 실습 데이터(전국 학교 설립 연도 데이터)를 활용해 Geo Map 위젯으로 학교 위치를 지도에 표시하고, Time Slice 위젯으로 연도별 학교 설립 현황 변화를 시각화합니다. 시각화 결과를 보며 '어느 지역에 학교가 많은가?', '언제 학교가 가장 많이 생겼는가?' 같은 인사이트를 도출하는 연습을 합니다. 확인 문제로 지리·시간 시각화 활용 사례 찾기, 도전 문제로 공공데이터포털에서 지리 데이터를 내려받아 Geo Map에 적용해보기로 마무리합니다.
