# 오렌지3, 처음 만나기 — 설치부터 첫 워크플로우까지

**Part 2**: Part 2. 빅데이터란 무엇인가 — 수집과 준비

---

## 학습 목표

- [ ] 오렌지3를 설치하고 기본 화면 구성(캔버스, 위젯, 연결선)을 설명할 수 있다.
- [ ] CSV 파일을 오렌지3에 불러와 데이터 테이블을 확인할 수 있다.
- [ ] File 위젯과 Data Table 위젯을 연결하는 기본 워크플로우를 만들 수 있다.

## 개요

생각해보기로 '코딩 없이도 데이터를 분석할 수 있다면 어떨까?'라며 오렌지3의 장점을 먼저 보여줍니다. 오렌지3 설치 방법을 스크린샷과 함께 단계별로 안내하고, 캔버스·위젯·연결선의 개념을 레고 블록 조립에 비유해 설명합니다. 구글 설문지에서 수집한 응답 데이터를 CSV로 내보내어 오렌지3에 불러오는 실습을 진행하며, File → Data Table 워크플로우를 직접 만들어봅니다. 확인 문제로 오렌지3 화면 구성 요소 찾기, 도전 문제로 위젯을 하나 더 추가해 데이터 요약 통계 확인하기로 마무리합니다.
