# 데이터를 그림으로 — 박스플롯, 히스토그램, 산점도

**Part 4**: Part 4. 데이터를 눈에 보이게 — 빅데이터 시각화

---

## 학습 목표

- [ ] 박스플롯, 히스토그램, 산점도의 특징과 적합한 사용 상황을 설명할 수 있다.
- [ ] 오렌지3의 Box Plot, Distributions, Scatter Plot 위젯을 활용해 시각화할 수 있다.
- [ ] 시각화 결과에서 데이터의 분포와 경향을 읽어낼 수 있다.

## 개요

생각해보기로 '우리 반 키 데이터를 한눈에 보여주려면 어떤 그래프가 좋을까?'라는 질문으로 시각화 방법 선택의 중요성을 인식합니다. 박스플롯(분포·이상치 파악), 히스토그램(빈도 분포), 산점도(두 변수 관계)의 특징을 비교표로 정리한 뒤, 교과서 실습 데이터를 활용해 오렌지3에서 Box Plot → Distributions → Scatter Plot 순서로 각각 만들어봅니다. 산점도에서 회귀선을 추가해 두 변수 간 관계를 파악하는 방법도 익힙니다. 확인 문제로 상황별 적합한 시각화 방법 고르기, 도전 문제로 자신의 설문 데이터에 세 가지 시각화를 모두 적용해보기로 마무리합니다.
