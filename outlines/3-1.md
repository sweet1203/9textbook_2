# 빠진 값, 이상한 값을 잡아라! — 결측치와 이상치 처리

**Part 3**: Part 3. 데이터를 다듬어라 — 빅데이터 전처리

---

## 학습 목표

- [ ] 결측치·이상치·오류 데이터의 의미와 발생 원인을 설명할 수 있다.
- [ ] 오렌지3의 Impute 위젯으로 결측치를 처리할 수 있다.
- [ ] Scatter Plot과 Select Rows 위젯으로 이상치를 발견하고 제거할 수 있다.

## 개요

생각해보기로 '설문지에 나이를 적는 칸에 누군가 999를 적었다면 어떻게 처리해야 할까?'라는 질문으로 이상치 문제를 체감합니다. 결측치(빈 값), 이상치(범위를 벗어난 값), 오류(잘못 입력된 값)의 차이를 예시와 함께 정리합니다. 교과서 실습 데이터(태양광 발전 데이터)를 오렌지3에 불러와 Impute 위젯으로 결측치를 처리하고, Scatter Plot으로 이상치를 시각적으로 발견한 뒤 Select Rows 위젯으로 제거하는 실습을 진행합니다. 확인 문제로 결측치·이상치·오류 구분하기, 도전 문제로 Formula 위젯을 활용해 조건식으로 이상치 필터링하기로 마무리합니다.
