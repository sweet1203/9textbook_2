# 문제를 발견하라 — 안전사고 데이터 수집과 전처리

**Part 6**: Part 6. 데이터로 문제를 해결하라 — 협력적 창의·융합 프로젝트

---

## 학습 목표

- [ ] 프로젝트 주제(여름 휴가철 안전사고)와 관련된 데이터를 공공데이터포털에서 수집할 수 있다.
- [ ] 수집한 데이터에서 결측치·이상치를 찾아 오렌지3로 전처리할 수 있다.
- [ ] 전처리 과정과 결과를 구글 슬라이드에 기록할 수 있다.

## 개요

생각해보기로 '매년 여름 바다에서 익사 사고가 반복되는 이유가 뭘까? 데이터로 원인을 찾을 수 있을까?'라는 질문으로 프로젝트의 사회적 의미를 느끼게 합니다. 모둠별로 공공데이터포털에서 여름철 안전사고 관련 데이터셋을 탐색하고 선택하는 활동을 진행합니다. 선택한 데이터를 오렌지3에 불러와 결측치·이상치를 확인하고 전처리하며, 전처리 전후 비교를 구글 슬라이드 첫 페이지에 기록합니다. 확인 문제로 전처리 체크리스트 점검, 도전 문제로 두 개 이상의 데이터셋을 Merge Data로 합쳐 더 풍부한 분석 준비하기로 마무리합니다.
