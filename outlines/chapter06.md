# 데이터 다듬기 ② - 선택하고 변환하기

**Part 3**: [1권] 데이터 다듬기 - 전처리의 기술

---

## 학습 목표

- [ ] 분석 목적에 맞게 필요한 열(속성)을 선택하고 불필요한 열을 제거할 수 있다.
- [ ] 오렌지3의 Select Columns, Edit Domain 위젯으로 데이터를 정리할 수 있다.
- [ ] 전처리 전후 데이터를 비교하여 변화를 확인하고 설명할 수 있다.

## 개요

마트에서 장을 볼 때 필요한 물건만 장바구니에 담듯, 데이터에서도 분석에 필요한 정보만 골라내는 과정이 중요합니다. 오렌지3의 Select Columns 위젯으로 열을 선택·제거하고, Edit Domain 위젯으로 데이터 유형(숫자형, 범주형)을 확인·변환하는 실습을 진행합니다. 전처리 전후 데이터를 Data Table에서 나란히 비교하며 달라진 점을 직접 확인합니다. 파이썬 코드로 열 선택과 타입 변환을 수행하는 화면도 함께 살펴봅니다. 확인 문제로 전처리 순서를 점검하고, 도전 문제로 '주어진 데이터에서 분석 목적에 맞는 열 3개를 스스로 선택하고 이유 쓰기'를 수행합니다.
