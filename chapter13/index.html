    Chapter 13: 보고서 완성 - 나의 데이터 보고서¶

    🎯 이 장에서 배우는 것¶

    • 데이터 분석 과정(문제 설정→수집→전처리→시각화→인사이트)을 체계적으로 보고서에 정리할 수 있다.
    • 시각화 자료를 효과적으로 배치하고 설명을 붙여 읽는 사람이 이해하기 쉬운 보고서를 작성할 수 있다.
    • 분석의 한계점과 추가 탐구 가능성을 보고서에 포함할 수 있다.

    💡 왜 이걸 배우나요?¶

    지금까지 여러분은 데이터를 수집하고, 정리하고, 시각화하고, 인사이트를 발견했습니다. 그런데 이 모든 과정이 여러분의 노트와 코드 파일에 흩어져 있다면 어떨까요?

    훌륭한 데이터 분석가도 결과를 잘 전달하지 못하면 그 가치가 반감됩니다. 실제로 데이터 분석 직종에서는 "분석 실력만큼 커뮤니케이션 실력이 중요하다"고 말합니다. 보고서는 여러분의 분석 과정과 결론을 다른 사람에게 설득력 있게 전달하는 도구입니다.

    이번 챕터에서는 그동안 했던 모든 작업을 하나의 완성된 보고서로 묶는 방법을 배웁니다. 보고서를 완성하고 나면, 여러분은 단순히 "분석을 해봤다"가 아니라 "내 분석 결과를 발표할 수 있다"고 말할 수 있게 됩니다. 🎉

    📚 핵심 개념¶

    개념 1: 데이터 보고서의 구조¶

    비유로 시작: 보고서는 여행기와 같습니다. 여행기에는 "왜 이 여행을 떠났는지", "어떤 곳을 방문했는지", "무엇을 경험했는지", "다음에 다시 간다면 무엇을 다르게 할 것인지"가 담깁니다. 데이터 보고서도 마찬가지입니다. 분석의 이유, 과정, 발견, 그리고 반성이 담겨야 합니다.

    정확한 정의: 데이터 보고서란 분석의 목적부터 결론까지 전체 과정을 독자가 이해할 수 있도록 체계적으로 정리한 문서입니다.

    예시로 확인: 좋은 보고서의 필수 구성 요소를 살펴봅시다.

    flowchart TD A["📋 보고서 제목\n분석 주제와 기간"] --> B["❓ 탐구 질문\n무엇을 알고 싶었나?"] B --> C["📦 데이터 출처\n어디서 데이터를 얻었나?"] C --> D["🔧 전처리 과정\n데이터를 어떻게 정리했나?"] D --> E["📊 시각화 결과\n어떤 그래프를 만들었나?"] E --> F["💡 인사이트\n무엇을 발견했나?"] F --> G["⚠️ 한계점 & 느낀점\n무엇이 부족했나?"]

    개념 2: 시각화 자료 설명하기¶

    비유로 시작: 미술관에서 그림 옆에는 항상 작품 설명 카드가 있습니다. 그림만 있으면 관람객은 무엇을 봐야 할지 모릅니다. 데이터 시각화도 마찬가지입니다. 그래프 옆에 "이 그래프에서 주목할 점은 X입니다"라는 설명이 없으면 독자는 무엇을 읽어야 할지 길을 잃습니다.

    정확한 정의: 시각화 자료 설명(캡션)이란 그래프나 표의 제목, 무엇을 보여주는지, 그리고 독자가 집중해야 할 핵심 패턴을 간결하게 적은 문장입니다.

    예시로 확인: 아래 두 가지를 비교해보세요.

    • 나쁜 예 → "다음은 막대 그래프입니다."
    • 좋은 예 → "그림 1. 월별 평균 기온 변화 (2023년). 7월과 8월에 평균 기온이 30°C를 넘어 여름철 더위가 집중됨을 보여준다."

    좋은 설명은 무엇을 보여주는지(제목) + 어떤 점이 중요한지(핵심 발견)를 한 문장에 담습니다.

    개념 3: 한계점 작성하기¶

    비유로 시작: 과학 실험 보고서에는 항상 "오차 원인"을 쓰는 칸이 있습니다. 실험이 완벽하지 않았다는 것을 솔직히 인정하는 것이 오히려 더 신뢰받는 보고서를 만듭니다. 데이터 분석도 똑같습니다.

    정확한 정의: 한계점이란 이번 분석에서 충분하지 않았던 부분, 또는 결론을 일반화하기 어려운 이유를 솔직하게 서술하는 항목입니다.

    예시로 확인: 한계점을 쓸 때 참고할 세 가지 질문

    • 데이터 한계 → "데이터가 충분한가? 기간이 너무 짧지 않은가?"
    • 분석 한계 → "더 정교한 분석 방법이 있었는가?"
    • 해석 한계 → "내 결론이 다른 원인으로 설명될 수도 있는가?"

    한계점을 쓴다고 보고서가 약해지는 것이 아닙니다. 오히려 "이 학생은 자신의 분석을 객관적으로 바라볼 줄 안다"는 인상을 줍니다. ✅

    개념 4: 핵심 메시지 한 문장 만들기¶

    비유로 시작: 뉴스 기사에는 제목이 있습니다. 제목은 기사 전체 내용을 한 줄로 요약합니다. 독자는 제목만 읽어도 핵심을 알 수 있습니다. 보고서의 핵심 메시지도 같은 역할을 합니다.

    정확한 정의: 핵심 메시지란 보고서 전체의 분석 결과를 독자가 기억할 수 있도록 한 문장으로 압축한 결론입니다.

    예시로 확인:

    • 약한 메시지 → "기온과 아이스크림 판매량을 분석해보았다."
    • 강한 메시지 → "기온이 25°C를 넘는 날, 아이스크림 판매량은 평균의 2.3배로 증가하며, 날씨가 소비 패턴에 직접적인 영향을 미친다."

    강한 핵심 메시지에는 구체적인 수치 + 명확한 관계 + 의미 해석이 담겨 있습니다.

    # 나의 데이터 분석 보고서

**제목:** 기온이 올라가면 아이스크림도 많이 팔릴까?
         - 서울시 기온과 아이스크림 판매량 분석

**작성자:** 홍길동
**작성일:** 2024년 6월 15일
**분석 도구:** Python (pandas, matplotlib)
**데이터 기간:** 2023년 1월 ~ 12월

---
## ❓ 탐구 질문
여름철 기온 상승이 아이스크림 판매량에 영향을 미치는지 확인하고,
기온과 판매량 사이에 어떤 관계가 있는지 수치로 파악한다.

    알아보기: 탐구 질문은 "예/아니오"로 끝나는 질문보다 "어떤 관계가 있는가?", "얼마나 차이가 나는가?"처럼 탐구를 유도하는 형태가 더 좋습니다.

    Step 2: 데이터 출처와 전처리 과정 정리하기¶

    독자가 "이 데이터가 믿을 만한가?"를 판단할 수 있도록 출처를 명확히 적습니다.

    ## 📦 데이터 출처

- **기온 데이터:** 기상청 기상자료개방포털 (data.kma.go.kr)
  - 서울 지점 월평균 기온 (2023년)
- **아이스크림 판매 데이터:** 통계청 소매판매업 조사 (2023년)
  - 아이스크림 및 냉과류 월별 판매 지수

---
## 🔧 전처리 과정

1. **결측값 확인:** 두 데이터 모두 결측값 없음 확인
2. **데이터 병합:** 월(month)을 기준으로 기온 데이터와 판매 데이터 합치기
3. **이상값 검토:** 2월 판매 지수가 낮게 나타났으나, 명절 연휴 영향으로 판단하여 유지
4. **컬럼 이름 통일:** 영문 컬럼명을 한글로 변경 (temp → 평균기온, sales → 판매지수)

    이 내용을 실제 Python 코드로도 기록해 두면 보고서의 재현 가능성이 높아집니다.

    import pandas as pd

# 데이터 불러오기
temp_df = pd.read_csv('seoul_temp_2023.csv')
sales_df = pd.read_csv('icecream_sales_2023.csv')

# 컬럼 이름 정리
temp_df.rename(columns={'temp': '평균기온'}, inplace=True)
sales_df.rename(columns={'sales': '판매지수'}, inplace=True)

# 월 기준으로 병합
merged_df = pd.merge(temp_df, sales_df, on='month')

# 결측값 확인
print("결측값 개수:", merged_df.isnull().sum())
print(merged_df.head())

    Step 3: 시각화 결과 삽입 및 설명 달기¶

    보고서에서 가장 중요한 부분입니다. 그래프를 삽입하고, 각 그래프마다 설명을 붙입니다.

    import matplotlib.pyplot as plt
import matplotlib.font_manager as fm

# 한글 폰트 설정
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 그래프 1: 월별 기온과 판매지수 추이
months = merged_df['month']
axes[0].plot(months, merged_df['평균기온'], marker='o', 
             color='tomato', label='평균기온(°C)')
axes[0].plot(months, merged_df['판매지수'], marker='s', 
             color='steelblue', label='판매지수')
axes[0].set_title('월별 기온 및 아이스크림 판매지수 변화')
axes[0].set_xlabel('월')
axes[0].legend()
axes[0].grid(True, alpha=0.3)

# 그래프 2: 기온 vs 판매지수 산점도
axes[1].scatter(merged_df['평균기온'], merged_df['판매지수'], 
                color='mediumpurple', s=80, alpha=0.7)
axes[1].set_title('기온과 판매지수의 관계 (산점도)')
axes[1].set_xlabel('평균기온 (°C)')
axes[1].set_ylabel('판매지수')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('report_figure1.png', dpi=150, bbox_inches='tight')
plt.show()

    Step 4: 인사이트 작성하기¶

    ## 💡 인사이트

**주요 발견 1: 강한 양의 상관관계 확인**
기온과 아이스크림 판매지수 사이의 상관계수는 0.94로,
매우 강한 양의 상관관계를 보인다.
기온이 1°C 오를수록 판매지수는 평균 약 3.2포인트 증가했다.

**주요 발견 2: 25°C 기준점 존재**
기온 25°C를 기준으로 판매지수 상승 속도가 눈에 띄게 빨라졌다.
이는 소비자들이 더위를 체감하기 시작하는 온도 임계점으로 해석된다.

**주요 발견 3: 겨울철 기저 판매량**
기온이 0°C 아래로 떨어지는 1월과 2월에도 판매지수 50 이상을
유지했다. 아이스크림이 계절에 상관없이 일정 수요를 가지는
'사계절 식품'임을 확인할 수 있다.

    Step 5: 한계점과 느낀점 작성하기¶

    ## ⚠️ 한계점

**데이터 한계:**
- 분석 기간이 1년(2023년)으로 짧아, 특정 연도의 이상 기후가
  결과에 영향을 미쳤을 가능성이 있다.
- 아이스크림 판매 데이터가 서울 전체 평균이 아닌 소매업 표본
  조사 기반이라 정확성에 한계가 있다.

**분석 한계:**
- 기온 외에 강수량, 주말 여부, 이벤트 등 다른 변수를 함께
  고려하지 못했다. 실제 판매량은 기온 단독으로 설명되지 않을 수 있다.

**해석 한계:**
- 상관관계가 있다고 해서 기온이 판매량을 '직접 결정한다'고
  단정할 수 없다. 두 변수에 공통으로 영향을 주는 다른 요인이
  있을 수 있다. (예: 여름철 야외 활동 증가)

## 💬 느낀점
데이터를 수집하고 정리하는 과정에서 '깨끗한 데이터'가
얼마나 중요한지 실감했다. 처음에는 기온과 판매량이 관련
있을 것이라 막연히 생각했는데, 실제 수치와 그래프로 확인하니
더 구체적으로 이해할 수 있었다. 다음에는 강수량 변수도 함께
분석해보고 싶다.

    📝 전체 코드¶

    아래는 보고서용 시각화를 한 번에 생성하는 전체 코드입니다. 여러분의 데이터에 맞게 파일명과 컬럼명만 바꾸면 바로 사용할 수 있습니다.

    import pandas as pd
import matplotlib.pyplot as plt

# ── 1. 환경 설정 ──
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

# ── 2. 데이터 준비 (예시 데이터) ──
data = {
    'month': list(range(1, 13)),
    '평균기온': [-2.4, 0.4, 6.1, 12.9, 18.2, 22.8,
                27.3, 28.1, 22.5, 15.8, 7.2, 0.6],
    '판매지수': [52, 55, 63, 74, 88, 102,
               135, 142, 98, 79, 61, 54]
}
df = pd.DataFrame(data)

# ── 3. 시각화 ──
fig, axes = plt.subplots(1, 2, figsize=(14, 5))
fig.suptitle('기온과 아이스크림 판매지수 분석 보고서', 
             fontsize=14, fontweight='bold')

# 꺾은선 그래프
ax1 = axes[0]
ax1.plot(df['month'], df['평균기온'], 'o-', color='tomato', label='평균기온(°C)')
ax1_twin = ax1.twinx()
ax1_twin.plot(df['month'], df['판매지수'], 's--', color='steelblue', label='판매지수')
ax1.set_xlabel('월')
ax1.set_ylabel('평균기온 (°C)', color='tomato')
ax1_twin.set_ylabel('판매지수', color='steelblue')
ax1.set_title('월별 변화 추이')
ax1.set_xticks(range(1, 13))
ax1.grid(True, alpha=0.3)

# 산점도
axes[1].scatter(df['평균기온'], df['판매지수'], 
                color='mediumpurple', s=80, alpha=0.8, zorder=5)
for i, row in df.iterrows():
    axes[1].annotate(f"{int(row['month'])}월",
                     (row['평균기온'], row['판매지수']),
                     textcoords='offset points', xytext=(5, 3), fontsize=8)
axes[1].set_xlabel('평균기온 (°C)')
axes[1].set_ylabel('판매지수')
axes[1].set_title('기온 vs 판매지수 산점도')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('report_final.png', dpi=150, bbox_inches='tight')
plt.show()

# ── 4. 상관계수 출력 ──
corr = df['평균기온'].corr(df['판매지수'])
print(f"상관계수: {corr:.2f}")
print("보고서 이미지 저장 완료: report_final.png")

    ⚠️ 자주 하는 실수¶

    실수 1: 그래프만 넣고 설명을 빠뜨리기 그래프를 보고서에 붙여넣고 설명 없이 다음 내용으로 넘어가는 경우가 많습니다. 독자는 그래프를 보고 "그래서 뭐가 중요하다는 거지?"라고 생각합니다. 반드시 "이 그래프에서 주목할 점은 ○○입니다"라는 한 문장을 추가하세요.

    실수 2: 한계점을 쓰지 않거나 너무 짧게 쓰기 "데이터가 부족했다" 한 줄로 끝내는 경우가 있습니다. 한계점은 구체적으로 "어떤 데이터가, 왜 부족했고, 그 결과 어떤 결론에 영향을 미쳤을 수 있는지"를 설명해야 합니다. 한계점이 구체적일수록 보고서의 신뢰도가 높아집니다.

    실수 3: 핵심 메시지에 수치가 없는 경우 "기온이 높으면 아이스크림이 많이 팔린다"는 핵심 메시지는 데이터 분석 보고서답지 않습니다. "상관계수 0.94", "25°C 기준점", "2.3배 증가" 처럼 분석에서 발견한 구체적인 수치를 반드시 포함하세요.

    실수 4: 데이터 출처를 모호하게 쓰기 "인터넷에서 찾은 데이터"처럼 출처를 모호하게 적으면 신뢰성이 떨어집니다. 웹사이트 이름, URL(가능하다면), 데이터 수집 날짜를 함께 기록하는 습관을 들이세요.

    📌 핵심 개념 정리¶

    보고서의 7가지 필수 구성 요소 - 제목 → 분석 주제와 기간을 포함 - 탐구 질문 → 무엇을 알고 싶었는가 - 데이터 출처 → 신뢰할 수 있는 출처를 구체적으로 - 전처리 과정 → 데이터를 어떻게 정리했는가 - 시각화 결과 → 그래프 + 설명(캡션) - 인사이트 → 수치와 함께 구체적인 발견 - 한계점 & 느낀점 → 솔직하고 구체적으로

    좋은 보고서의 핵심 원칙 - 그래프에는 반드시 설명을 붙인다 - 한계점은 솔직하게, 구체적으로 쓴다 - 핵심 메시지는 수치와 함께 한 문장으로 압축한다 - 독자가 데이터 없이 읽어도 이해할 수 있어야 한다
