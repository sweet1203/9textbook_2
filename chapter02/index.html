    Chapter 02. 비밀을 지켜라! — 암호화의 기본¶

    🎯 이 장에서 배우는 것¶

    • 암호화가 무엇인지, 왜 필요한지 설명할 수 있다.
    • 카이사르 암호의 원리를 이해하고 직접 메시지를 암호화·복호화할 수 있다.
    • 일상생활 속에서 암호화가 사용되는 사례를 3가지 이상 말할 수 있다.
    • 파이썬으로 카이사르 암호를 구현한 코드를 읽고 실행할 수 있다.

    💡 왜 이걸 배우나요?¶

    🤔 생각해보기: 친구에게 중요한 쪽지를 보내려고 합니다. 그런데 선생님이나 다른 친구가 중간에 그 쪽지를 볼 수도 있다면 어떻게 할까요?

    우리는 매일 엄청난 양의 정보를 주고받습니다. 카카오톡 메시지, 인터넷 쇼핑 결제, 학교 성적 조회… 이 모든 정보가 인터넷을 통해 이동할 때, 중간에 누군가가 훔쳐볼 수 있다면 어떻게 될까요?

    암호화(Encryption) 는 바로 이 문제를 해결하는 기술입니다. 중요한 정보를 아무도 알아볼 수 없는 형태로 변환해서, 오직 허락받은 사람만 내용을 볼 수 있게 만드는 것이죠.

    암호화는 수천 년 전부터 사용되어 왔고, 오늘날 디지털 세상에서는 없어서는 안 될 기술이 되었습니다. 이 장에서는 암호화의 가장 기본적인 원리를 배우고, 직접 코드로 구현해 봅니다.

    📚 핵심 개념¶

    개념 1: 암호화란 무엇인가?¶

    비유로 시작 🔒

    자물쇠와 열쇠를 생각해보세요. 중요한 일기장을 자물쇠가 달린 상자에 넣으면, 열쇠를 가진 사람만 일기를 읽을 수 있습니다. 암호화는 디지털 세계의 자물쇠와 열쇠입니다. 정보(일기장)를 잠그고(암호화), 열쇠(복호화 키)를 가진 사람만 내용을 볼 수 있게 합니다.

    정확한 정의 📖

    • 암호화(Encryption): 알아볼 수 있는 정보(평문)를 특정 규칙을 사용해 알아볼 수 없는 형태(암호문)로 변환하는 과정
    • 복호화(Decryption): 암호문을 다시 원래의 평문으로 되돌리는 과정
    • 평문(Plaintext): 암호화되기 전의 원본 데이터
    • 암호문(Ciphertext): 암호화된 후의 데이터
    • 키(Key): 암호화와 복호화에 사용되는 규칙이나 값

    흐름으로 확인 🔄

    flowchart LR A["📄 평문\n'안녕하세요'"] -->|암호화 + 키| B["🔒 암호문\n'#$@!%^'"] B -->|복호화 + 키| C["📄 평문\n'안녕하세요'"] style A fill:#d4edda,stroke:#28a745 style B fill:#f8d7da,stroke:#dc3545 style C fill:#d4edda,stroke:#28a745

    📌 정리하기: 암호화 = 평문 → 암호문, 복호화 = 암호문 → 평문

    개념 2: 카이사르 암호¶

    비유로 시작 🏛️

    약 2,000년 전, 로마의 장군 율리우스 카이사르(Julius Caesar)는 전쟁터에서 비밀 명령을 전달할 때 특별한 방법을 사용했습니다. 알파벳을 일정한 숫자만큼 밀어서 쓰는 방법이었습니다. 예를 들어 3칸씩 밀면 A는 D가 되고, B는 E가 되는 방식입니다.

    정확한 정의 📖

    카이사르 암호(Caesar Cipher) 는 알파벳의 각 글자를 일정한 수(이동 값, shift)만큼 뒤로 밀어서 암호화하는 방법입니다. 이동 값이 키(Key) 역할을 합니다.

    예시로 확인 ✏️

    이동 값(키) = 3일 때:

    flowchart LR subgraph 원래 알파벳 A1[A] --> B1[B] --> C1[C] --> D1[D] --> E1[E] end subgraph 3칸 이동한 알파벳 D2[D] --> E2[E] --> F2[F] --> G2[G] --> H2[H] end style A1 fill:#cce5ff style B1 fill:#cce5ff style C1 fill:#cce5ff style D1 fill:#cce5ff style E1 fill:#cce5ff style D2 fill:#fff3cd style E2 fill:#fff3cd style F2 fill:#fff3cd style G2 fill:#fff3cd style H2 fill:#fff3cd
    • 평문: HELLO
    • 암호화 (각 글자 +3): H→K, E→H, L→O, L→O, O→R
    • 암호문: KHOOR

    복호화할 때는 반대로 -3 하면 됩니다.

    📌 알아보기: Z 다음은 어떻게 될까요? Z(26번째)에 3을 더하면 29번째인데, 알파벳은 26개뿐입니다. 이럴 때는 나머지 연산(mod)을 사용합니다. 29 mod 26 = 3, 즉 C가 됩니다. 알파벳이 원형으로 이어진다고 생각하세요! 🔄

    개념 3: 일상 속 암호화 사례¶

    암호화는 이미 우리 일상 곳곳에 숨어 있습니다.

    🌐 HTTPS와 자물쇠 아이콘

    웹 브라우저 주소창을 보면 https://와 함께 🔒 자물쇠 아이콘이 보입니다. 이것은 해당 웹사이트와 내 컴퓨터 사이의 통신이 암호화되어 있다는 표시입니다. HTTP와 HTTPS의 차이를 살펴보겠습니다.

    flowchart TD A[사용자] -->|HTTP: 암호화 없음 ❌| B[웹서버] A -->|HTTPS: 암호화 있음 ✅| C[웹서버] B --> D["😨 중간에서 내용을\n그대로 볼 수 있음"] C --> E["😊 중간에서 봐도\n암호문만 보임"] style D fill:#f8d7da,stroke:#dc3545 style E fill:#d4edda,stroke:#28a745

    💬 카카오톡 종단간 암호화

    카카오톡 '비밀 채팅' 기능은 종단간 암호화(End-to-End Encryption) 를 사용합니다. 메시지가 발신자 기기에서 암호화되어, 수신자 기기에서만 복호화됩니다. 중간에 서버를 거쳐도 내용을 알 수 없습니다.

    🏧 비밀번호 저장

    여러분이 웹사이트에 가입할 때 입력한 비밀번호는 서버에 그대로 저장되지 않습니다. 해시(Hash) 라는 암호화 기법을 통해 변환된 값이 저장됩니다. 그래서 해킹을 당해도 원본 비밀번호가 유출되지 않습니다.

    개념 4: 암호화가 중요한 이유¶

    🤔 생각해보기: 암호화가 없다면 어떤 일이 생길까요?

    mindmap root((암호화가\n없다면?)) 개인정보 유출 이름, 주소 노출 전화번호 도용 금융 피해 신용카드 번호 도난 인터넷 뱅킹 해킹 사생활 침해 메시지 내용 노출 위치 정보 추적 국가 안보 위협 기밀 문서 유출 군사 정보 도난

    암호화는 단순한 기술이 아닙니다. 개인의 프라이버시를 지키고, 금융 거래를 안전하게 하며, 나아가 국가 안보까지 보호하는 핵심 기술입니다.

    🔨 따라하기¶

    Step 1: 종이로 카이사르 암호 체험하기¶

    먼저 컴퓨터 없이 직접 손으로 암호화를 해봅시다.

    준비물: 연필, 종이

    알파벳 위치표를 활용하세요:

    • A=1, B=2, C=3, D=4, E=5, F=6, G=7, H=8, I=9, J=10
    • K=11, L=12, M=13, N=14, O=15, P=16, Q=17, R=18, S=19, T=20
    • U=21, V=22, W=23, X=24, Y=25, Z=26

    이동 값(키) = 3으로 PYTHON을 암호화해보세요.

    • P (16) + 3 = 19 → S
    • Y (25) + 3 = 28 → 28 - 26 = 2 → B
    • T (20) + 3 = 23 → W
    • H (8) + 3 = 11 → K
    • O (15) + 3 = 18 → R
    • N (14) + 3 = 17 → Q

    결과: PYTHON → SBWKRQ ✅

    ✏️ 직접 해보기: 이동 값 3으로 HELLO WORLD를 암호화해보세요! (정답은 이 장 맨 끝에 있습니다)

    Step 2: 파이썬 환경 준비¶

    파이썬이 설치되어 있다면 IDLE이나 VS Code를 열어주세요. 아직 설치하지 않았다면 선생님께 도움을 요청하거나, 브라우저에서 replit.com에 접속해 온라인으로 실행할 수 있습니다.

    새 파일을 만들고 이름을 caesar.py로 저장합니다.

    Step 3: 암호화 함수 작성하기¶

    아래 코드를 한 줄씩 천천히 입력해보세요. 복사-붙여넣기보다 직접 타이핑하면 더 잘 이해됩니다!

    def encrypt(text, shift):
    """카이사르 암호로 암호화하는 함수"""
    result = ""  # 암호문을 담을 빈 문자열

    for char in text:  # 문자를 하나씩 처리
        if char.isalpha():  # 알파벳인 경우만 처리
            # 대문자와 소문자를 구분
            if char.isupper():
                base = ord('A')  # 대문자 기준점 (65)
            else:
                base = ord('a')  # 소문자 기준점 (97)

            # 핵심 공식: (현재위치 + 이동값) % 26
            shifted = (ord(char) - base + shift) % 26
            result += chr(base + shifted)
        else:
            result += char  # 알파벳이 아니면 그대로 추가

    return result

    📌 알아보기: ord() 함수는 문자를 숫자로 바꿉니다. ord('A')는 65입니다. 반대로 chr() 함수는 숫자를 문자로 바꿉니다. chr(65)는 'A'입니다.

    Step 4: 복호화 함수 작성하기¶

    복호화는 암호화의 반대입니다. 이동 값을 반대 방향으로 적용하면 됩니다.

    def decrypt(text, shift):
    """카이사르 암호를 복호화하는 함수"""
    # 복호화는 반대 방향으로 이동 = 26에서 shift를 빼면 됨
    return encrypt(text, 26 - shift)

    📌 핵심 아이디어: 이동 값이 3이면, 복호화는 -3만큼 이동하는 것입니다. 파이썬에서는 -3 % 26 = 23이므로, 26 - 3 = 23을 이동 값으로 사용해도 같은 결과가 나옵니다.

    Step 5: 메인 코드 작성하고 실행하기¶

    # 메인 실행 코드
if __name__ == "__main__":
    # 암호화 테스트
    original = "Hello Python"
    key = 3

    encrypted = encrypt(original, key)
    decrypted = decrypt(encrypted, key)

    print(f"원본 메시지  : {original}")
    print(f"암호화 결과  : {encrypted}")
    print(f"복호화 결과  : {decrypted}")
    print(f"복호화 성공? : {original == decrypted}")

    실행 결과:

    원본 메시지  : Hello Python
암호화 결과  : Khoor Sbwkrq
복호화 결과  : Hello Python
복호화 성공? : True

    Step 6: 나만의 메시지 암호화하기¶

    이제 직접 메시지와 키를 바꿔서 실험해보세요!

    # 직접 수정해서 실험해보세요!
my_message = "My name is 홍길동"  # 여기에 원하는 메시지 입력
my_key = 7                        # 1~25 사이의 숫자로 키 변경

my_encrypted = encrypt(my_message, my_key)
my_decrypted = decrypt(my_encrypted, my_key)

print(f"내 메시지   : {my_message}")
print(f"암호화      : {my_encrypted}")
print(f"복호화      : {my_decrypted}")

    💡 참고: 한글은 카이사르 암호로 처리되지 않아 그대로 출력됩니다. 알파벳만 암호화됩니다. 한글 암호화는 훨씬 복잡한 방법이 필요합니다.

    📝 전체 코드¶

    지금까지 작성한 코드를 한 곳에 모았습니다. 이 코드를 caesar.py로 저장하면 완성입니다!

    # caesar.py
# 카이사르 암호 구현

def encrypt(text, shift):
    """카이사르 암호로 암호화하는 함수"""
    result = ""

    for char in text:
        if char.isalpha():
            if char.isupper():
                base = ord('A')
            else:
                base = ord('a')

            shifted = (ord(char) - base + shift) % 26
            result += chr(base + shifted)
        else:
            result += char

    return result


def decrypt(text, shift):
    """카이사르 암호를 복호화하는 함수"""
    return encrypt(text, 26 - shift)


if __name__ == "__main__":
    original = "Hello Python"
    key = 3

    encrypted = encrypt(original, key)
    decrypted = decrypt(encrypted, key)

    print(f"원본 메시지  : {original}")
    print(f"암호화 결과  : {encrypted}")
    print(f"복호화 결과  : {decrypted}")
    print(f"복호화 성공? : {original == decrypted}")

    ⚠️ 자주 하는 실수¶

    실수 1: 이동 값으로 26 이상을 사용하기

    이동 값이 26이면 A → A로 돌아와 암호화가 되지 않습니다. 이동 값은 1~25 사이를 사용하세요. 코드에서는 % 26 덕분에 자동으로 처리되지만, 의미 있는 암호화를 위해서 적절한 값을 선택해야 합니다.

    # 잘못된 예
encrypt("HELLO", 26)   # 결과: HELLO (암호화 안 됨!)

# 올바른 예
encrypt("HELLO", 13)   # 결과: URYYB

    실수 2: 복호화 시 다른 키를 사용하기

    암호화할 때 사용한 키와 정확히 같은 키로 복호화해야 합니다. 다른 키를 사용하면 엉뚱한 결과가 나옵니다.

    encrypted = encrypt("HELLO", 3)  # 키 3으로 암호화
decrypt(encrypted, 5)  # ❌ 키 5로 복호화하면 틀림
decrypt(encrypted, 3)  # ✅ 키 3으로 복호화해야 함

    실수 3: 소문자와 대문자 기준점 혼동

    ord('A')는 65, ord('a')는 97로 다릅니다. 대문자와 소문자를 구분하지 않으면 암호화 결과가 알파벳 범위를 벗어나 이상한 문자가 나올 수 있습니다. 코드에서 isupper()로 구분하는 이유가 바로 이것입니다.

    # 잘못된 예 (기준점을 하나로만 사용)
shifted = (ord('a') - ord('A') + 3) % 26  # 결과 예측 불가

# 올바른 예 (대/소문자 구분)
if char.isupper():
    base = ord('A')  # 65
else:
    base = ord('a')  # 97

    실수 4: 카이사르 암호가 강력한 암호라고 오해하기

    카이사르 암호의 이동 값은 1~25, 딱 25가지뿐입니다. 컴퓨터는 25번만 시도하면 무조건 풀 수 있습니다. 카이사르 암호는 암호화의 원리를 배우기 위한 교육용 암호이며, 실제 중요한 데이터 보호에는 절대 사용하면 안 됩니다. 현대 암호화(AES, RSA 등)는 훨씬 복잡한 수학을 사용합니다.

    도전 2: 암호 해독기 만들기 ⭐⭐

    카이사르 암호는 이동 값이 25가지뿐입니다. 이동 값을 모를 때 모든 경우를 시도해서 원래 메시지를 찾는 브루트포스(brute force) 해독기를 만들어보세요.

    def crack_caesar(ciphertext):
    """모든 이동 값을 시도해서 출력하는 함수"""
    print("=== 모든 가능한 복호화 결과 ===")
    for shift in range(1, 26):
        result = decrypt(ciphertext, shift)
        print(f"이동값 {shift:2d}: {result}")

# 테스트
