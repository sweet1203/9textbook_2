    데이터가 너무 커요! - 압축의 세계¶

    🎯 이 장에서 배우는 것¶

    • 데이터 압축이 필요한 이유를 일상 사례를 통해 설명할 수 있다.
    • 손실 압축과 무손실 압축의 차이를 구분하고 각각의 예시를 들 수 있다.
    • ZIP, JPEG, PNG, MP3 등 주요 압축 형식이 어떤 상황에 쓰이는지 말할 수 있다.
    • 데이터 압축이 저장 공간과 에너지 절약, 탄소중립에 기여하는 방식을 이해한다.

    💡 왜 이걸 배우나요?¶

    스마트폰으로 사진을 찍으면 한 장에 수 MB가 됩니다. 4K 영상은 1분에 수백 MB를 넘기도 하죠. 그런데 우리는 수천 장의 사진을 스마트폰에 저장하고, 유튜브 영상을 끊김 없이 봅니다. 어떻게 이게 가능할까요?

    답은 압축(Compression) 입니다.

    압축을 이해하면 단순히 파일 크기를 줄이는 기술 그 이상을 알게 됩니다. 어떤 압축은 원본을 완벽하게 복원하고, 어떤 압축은 약간의 품질을 포기하는 대신 훨씬 작게 만듭니다. 이 차이를 모르면 중요한 문서를 압축했다가 데이터가 손상되는 낭패를 볼 수도 있습니다.

    또한 전 세계 데이터 센터가 소비하는 전기는 일부 국가의 전체 전력 소비량을 넘어설 정도입니다. 압축 기술은 단순히 편리함을 넘어 에너지 절약과 환경 보호에도 직결된 중요한 기술입니다.

    📚 핵심 개념¶

    개념 1: 데이터 압축이란 무엇인가?¶

    🧳 여행 가방 비유로 시작하기¶

    여행을 떠나기 전 가방을 쌀 때를 생각해보세요. 옷을 그냥 넣으면 가방이 금방 꽉 차버립니다. 하지만 옷을 돌돌 말아 넣거나, 진공 압축 팩에 넣어 공기를 빼면 같은 가방에 훨씬 많은 옷을 담을 수 있습니다.

    데이터 압축도 똑같습니다. 파일 속 정보를 더 효율적인 방식으로 표현해서 파일 크기를 줄이는 기술입니다.

    정확한 정의 데이터 압축이란 같은 정보를 더 적은 비트(bit)로 표현하는 기술입니다. 불필요하게 반복되는 부분을 줄이거나, 덜 중요한 정보를 제거해서 파일 크기를 작게 만듭니다.

    예시로 확인하기¶

    글자 예시를 하나 봅시다. 다음 문장이 있다고 가정하겠습니다.

    AAAAABBBBBCCCCC

    이 15개의 글자를 그냥 저장하면 15바이트가 필요합니다. 하지만 이렇게 표현하면 어떨까요?

    A5B5C5

    "A가 5번, B가 5번, C가 5번"이라는 뜻입니다. 단 6바이트로 같은 정보를 담았습니다. 이런 방식을 런-길이 부호화(Run-Length Encoding, RLE) 라고 하며, 가장 단순한 압축 방식 중 하나입니다.

    개념 2: 무손실 압축 (Lossless Compression)¶

    📦 진공 팩 비유¶

    무손실 압축은 진공 팩과 같습니다. 옷을 진공 팩에 넣으면 부피가 줄어들지만, 꺼내서 공기를 불어넣으면 원래 옷 그대로 돌아옵니다. 정보가 하나도 손실되지 않습니다.

    정확한 정의 무손실 압축은 압축된 파일을 다시 풀었을 때(압축 해제) 원본 데이터와 100% 동일하게 복원되는 압축 방식입니다.

    대표적인 무손실 압축 형식¶

    • ZIP : 문서, 폴더 등 다양한 파일을 묶어 압축하는 범용 형식
    • PNG : 투명도를 지원하는 이미지 형식, 원본 픽셀 정보를 완벽히 보존
    • FLAC : 음악 파일을 원본 품질 그대로 압축하는 오디오 형식
    • GIF : 움직이는 이미지를 지원하는 무손실 형식 (단, 색상 수 제한)

    언제 써야 할까?¶

    무손실 압축은 복원했을 때 데이터가 정확히 같아야 하는 경우에 반드시 사용해야 합니다.

    • 실행 프로그램(.exe 파일)
    • 중요한 문서(계약서, 논문, 소스 코드)
    • 의료 영상(X-ray, CT 사진)

    💬 생각해보기 프로그램 파일을 손실 압축하면 어떻게 될까요? 파일을 열었을 때 원래 코드와 달라져서 프로그램이 실행되지 않거나 오작동할 수 있습니다!

    개념 3: 손실 압축 (Lossy Compression)¶

    📸 사진 인화 비유¶

    원본 사진을 크게 인화하면 선명하지만, 작게 인화하면 세부 표현이 조금 사라집니다. 그런데 멀리서 보면 큰 차이를 못 느끼죠. 손실 압축이 이와 비슷합니다. 사람이 눈이나 귀로 잘 느끼지 못하는 정보를 과감히 제거해서 파일을 훨씬 작게 만듭니다.

    정확한 정의 손실 압축은 압축 과정에서 일부 데이터를 영구적으로 제거하는 방식입니다. 압축을 풀어도 원본과 완전히 같지 않지만, 사람이 인지하기 어려운 부분을 제거하기 때문에 실용적으로 사용할 수 있습니다.

    대표적인 손실 압축 형식¶

    • JPEG (JPG) : 가장 널리 쓰이는 이미지 형식. 색상이 복잡한 사진에 적합
    • MP3 : 사람 귀에 잘 들리지 않는 주파수를 제거해 음악 파일을 압축
    • MP4 (H.264, H.265) : 동영상 압축 형식. 각 프레임의 변화량만 저장해 용량 절감

    손실 압축의 특징: 품질 조절 가능¶

    손실 압축은 대부분 압축 품질을 조절할 수 있습니다. JPEG 이미지를 저장할 때 품질을 100%로 설정하면 거의 손상이 없지만 파일이 크고, 10%로 설정하면 파일이 매우 작아지는 대신 이미지가 뭉개집니다.

    graph LR A["원본 이미지<br/>10MB"] --> B["JPEG 품질 90%<br/>1.5MB"] A --> C["JPEG 품질 50%<br/>0.5MB"] A --> D["JPEG 품질 10%<br/>0.1MB"] B --> E["🟢 거의 차이 없음"] C --> F["🟡 약간 차이 보임"] D --> G["🔴 품질 저하 뚜렷"]

    🌱 압축과 탄소중립¶

    데이터 압축은 환경 문제와도 연결됩니다.

    압축이 없다면 어떻게 될까요?

    • 더 많은 저장 공간이 필요 → 더 많은 하드디스크와 서버 필요
    • 파일 전송에 더 많은 시간과 네트워크 에너지 소비
    • 데이터 센터의 냉각에 더 많은 전기 사용

    한 연구에 따르면 전 세계 데이터 센터는 전체 전력의 약 1~2%를 소비하며, 이는 일부 국가의 전체 항공 산업과 맞먹는 수준입니다. 압축 기술이 1%의 데이터만 더 효율적으로 처리해도, 이는 어마어마한 에너지 절약으로 이어집니다.

    📌 한 문장 정리 데이터를 압축하면 저장 공간과 전송 시간이 줄어들고, 이는 서버 운영에 필요한 전력 소비를 낮춰 탄소 배출 감소에 기여합니다.

    🔨 따라하기: 윈도우에서 파일 압축과 해제¶

    이제 직접 파일을 압축해봅시다. 윈도우에 기본으로 내장된 압축 기능을 사용하므로 별도 프로그램 설치가 필요 없습니다.

    Step 1: 압축할 파일 준비하기¶

    1. 바탕화면에 새 폴더를 하나 만드세요. 이름은 압축_실습으로 지정합니다.
    2. 폴더 안에 메모장을 열고 다음 내용을 입력하세요.
    안녕하세요 안녕하세요 안녕하세요
데이터 압축 실습입니다.
이 파일을 압축해보겠습니다.
    1. 파일 이름을 연습.txt로 저장합니다.
    2. 그림판을 열어 아무 그림이나 그리고 그림.bmp로 저장합니다. (BMP는 비압축 이미지 형식입니다.)

    💡 알아보기: BMP 파일은 이미지 데이터를 압축 없이 저장하기 때문에 같은 이미지도 JPEG나 PNG보다 훨씬 큽니다. 비교 실습을 위해 의도적으로 사용하는 것입니다.

    Step 2: 폴더를 ZIP으로 압축하기¶

    1. 압축_실습 폴더를 마우스 오른쪽 버튼으로 클릭합니다.
    2. 메뉴에서 다음을 선택합니다.
    3. 윈도우 10: 보내기 → 압축(zip) 폴더
    4. 윈도우 11: 추가 옵션 표시 → 보내기 → 압축(zip) 폴더
    5. 잠시 기다리면 같은 위치에 압축_실습.zip 파일이 생성됩니다.

    Step 3: 압축 전후 크기 비교하기¶

    1. 원본 압축_실습 폴더를 오른쪽 클릭 → 속성을 선택합니다.
    2. 크기와 디스크 할당 크기를 메모해두세요.
    3. 똑같이 압축_실습.zip의 속성도 확인합니다.

    🔍 확인 포인트: 원본보다 ZIP 파일이 더 작아졌나요? BMP처럼 반복 패턴이 많은 파일은 압축 효과가 큽니다. 반면 이미 JPEG로 압축된 파일은 ZIP으로 다시 압축해도 별로 작아지지 않습니다.

    Step 4: ZIP 파일 압축 해제하기¶

    1. 압축_실습.zip을 오른쪽 클릭합니다.
    2. 모두 압축 풀기를 선택합니다.
    3. 압축을 풀 위치를 선택하고 압축 풀기 버튼을 누릅니다.
    4. 압축이 풀린 폴더를 열어 파일들이 원본과 동일한지 확인합니다.

    ✅ 무손실 압축(ZIP)이기 때문에 연습.txt와 그림.bmp는 압축 전과 완전히 동일합니다.

    Step 5: JPEG와 PNG 비교하기 (손실 vs 무손실)¶

    그림판에서 저장한 그림.bmp 파일을 두 가지 형식으로 저장해 비교합니다.

    1. 그림.bmp를 그림판으로 엽니다.
    2. 파일 → 다른 이름으로 저장 → JPEG 그림으로 저장합니다. 파일 이름: 그림_손실.jpg
    3. 다시 파일 → 다른 이름으로 저장 → PNG 그림으로 저장합니다. 파일 이름: 그림_무손실.png
    4. 세 파일의 크기를 비교합니다.

    예상 결과 (단순한 그림 기준)

    • 그림.bmp : 가장 큰 크기 (비압축)
    • 그림_무손실.png : 중간 크기 (무손실 압축)
    • 그림_손실.jpg : 가장 작은 크기 (손실 압축)

    Step 6: 시각적으로 차이 확인하기¶

    1. 그림_손실.jpg를 확대해서 보세요. 색이 뚜렷이 바뀌는 경계 부분에서 약간 뭉개지거나 번진 것처럼 보이는 현상이 나타날 수 있습니다. 이를 JPEG 아티팩트(Artifact) 라고 합니다.
    2. 그림_무손실.png는 원본 BMP와 시각적으로 동일하게 보입니다.

    💬 생각해보기: 사진 파일을 JPEG로 여러 번 저장하고 다시 열고를 반복하면 어떻게 될까요? 저장할 때마다 손실이 누적되어 품질이 점점 떨어집니다. 원본 사진은 반드시 무손실 형식(RAW, PNG)으로 보관하는 것이 좋습니다.

    ⚠️ 자주 하는 실수¶

    실수 1: 이미 압축된 파일을 다시 ZIP으로 압축하기

    MP3, JPEG, MP4 같은 파일은 이미 압축되어 있습니다. 이 파일들을 ZIP으로 묶어도 파일 크기가 거의 줄어들지 않습니다. 오히려 ZIP 헤더 정보가 추가되어 약간 더 커질 수도 있습니다. 이미 압축된 파일들은 ZIP을 쓰는 주된 이유가 "묶기(번들링)" 이지, 용량 절감이 목적이 아님을 기억하세요.

    실수 2: 중요한 파일을 손실 압축 형식으로 저장하기

    계약서나 성적표를 스캔한 이미지를 JPEG로만 저장하는 경우가 있습니다. JPEG는 품질이 설정에 따라 크게 달라지고, 텍스트처럼 선명한 경계가 있는 이미지에서 아티팩트가 더 심하게 나타납니다. 중요한 문서 이미지는 PNG로 저장하는 것이 바람직합니다.

    실수 3: 압축 파일이 원본보다 큰 경우를 이상하게 생각하기

    매우 작은 파일(예: 몇 십 바이트짜리 텍스트 파일)을 ZIP으로 압축하면 오히려 더 커질 수 있습니다. 이는 ZIP 파일 자체의 구조 정보(파일 이름, 날짜, 체크섬 등)를 저장하는 오버헤드 때문입니다. 압축은 파일이 충분히 클 때 효과적입니다.

    실수 4: 손실 압축을 무조건 나쁘다고 생각하기

    손실 압축은 "데이터가 손상된다"는 표현 때문에 부정적으로 느껴질 수 있습니다. 하지만 사람의 감각으로 구분하기 어려운 정보를 제거하는 것이라, 일상적인 사진 공유나 음악 감상에는 전혀 문제가 없습니다. 용도에 맞게 선택하는 것이 중요합니다.

    📌 핵심 개념 요약¶

    데이터 압축 같은 정보를 더 적은 비트로 표현해 파일 크기를 줄이는 기술.

    무손실 압축 (Lossless) 원본을 100% 복원 가능. 대표 형식: ZIP, PNG, FLAC. 중요한 문서, 실행 파일, 의료 데이터에 사용.

    손실 압축 (Lossy) 사람이 인지하기 어려운 정보를 제거. 복원 불가. 대표 형식: JPEG, MP3, MP4. 사진 공유, 음악 감상, 동영상 스트리밍에 사용.

    압축과 환경 데이터 압축 → 저장 공간 및 전송 에너지 절약 → 탄소 배출 감소에 기여.
