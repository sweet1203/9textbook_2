    Chapter 08. 데이터를 그림으로 ② — 지도와 시간 시각화¶

    🎯 이 장에서 배우는 것¶

    • 위도·경도 데이터를 오렌지3 Geo Map 위젯으로 지도 위에 시각화할 수 있다
    • 시간에 따라 변화하는 데이터를 선 그래프(Line Plot)로 표현하고 추이를 읽을 수 있다
    • 파이썬 folium과 matplotlib으로 지도·시간 시각화를 직접 실행할 수 있다
    • 데이터의 성격에 맞는 시각화 유형을 스스로 선택하고 이유를 설명할 수 있다

    💡 왜 이걸 배우나요?¶

    뉴스에서 "전국 확진자 분포"를 지도 위 점으로 보여준 기억이 있나요? 또는 "최근 10년간 평균 기온 변화"를 구불구불한 선으로 표현한 그래프를 본 적 있나요?

    숫자만 나열된 표를 볼 때와 지도·선 그래프로 볼 때 우리 뇌가 받아들이는 정보의 양은 완전히 다릅니다. "어디에서 일어났는가" 를 보여줄 때는 지도가, "언제 어떻게 바뀌었는가" 를 보여줄 때는 선 그래프가 가장 강력한 도구입니다.

    이번 장에서는 이 두 가지 시각화를 직접 만들어보고, 나아가 "이 데이터에는 어떤 그래프가 가장 잘 어울릴까?"를 스스로 판단하는 능력을 기릅니다. 이 능력은 데이터 분석가, 기자, 기획자 등 수많은 직업에서 매일 사용하는 핵심 스킬입니다.

    📚 핵심 개념¶

    개념 1: 지리 데이터와 지도 시각화¶

    비유로 시작 🗺️

    보물지도를 생각해보세요. "북쪽으로 50걸음, 동쪽으로 30걸음"이라는 숫자보다 지도 위 X 표시 하나가 훨씬 직관적으로 위치를 알려줍니다. 데이터도 마찬가지입니다. "위도 37.5, 경도 127.0"이라는 숫자 두 개보다 지도 위 점 하나가 "여기!"를 훨씬 빠르게 전달합니다.

    정확한 정의

    지리 데이터(Geographic Data)란 위도(Latitude)와 경도(Longitude) 좌표를 포함한 데이터입니다. 지도 시각화는 이 좌표를 실제 지도 위에 점·색깔·크기 등으로 표현해 공간적 패턴을 드러내는 방법입니다.

    • 위도(Latitude): 적도에서 남북 방향 거리 (-90 ~ +90)
    • 경도(Longitude): 영국 그리니치에서 동서 방향 거리 (-180 ~ +180)
    • 서울의 좌표: 위도 37.57°N, 경도 126.98°E

    예시로 확인 ✅

    아래 두 가지 데이터를 비교해보세요.

    표로 볼 때: - 강남구 편의점 수: 312개 - 도봉구 편의점 수: 89개 - 중구 편의점 수: 201개

    지도로 볼 때: 강남구 지역이 점이 빽빽하고, 도봉구는 듬성듬성합니다. 지도를 보는 순간 "강남에 편의점이 몰려있구나"를 0.5초 만에 파악할 수 있습니다.

    개념 2: 시간 데이터와 선 그래프¶

    비유로 시작 📈

    성장 앨범을 생각해보세요. 매년 키를 잰 숫자들(150cm, 157cm, 163cm, 168cm)을 늘어놓으면 "많이 컸구나" 정도만 알 수 있습니다. 그런데 이 숫자들을 선으로 이으면 "언제 가장 빨리 자랐는지", "성장이 둔화된 시점이 언제인지" 까지 한눈에 보입니다.

    정확한 정의

    선 그래프(Line Plot)는 시간 축(X축)에 따라 값이 어떻게 변화하는지를 선으로 연결해 보여주는 시각화입니다. 핵심은 연속성입니다. 점과 점 사이가 이어져 있다는 것은 "그 사이에도 값이 존재했다"는 의미를 담습니다.

    선 그래프가 가장 적합한 데이터: - 기온 변화: 1월부터 12월까지 월평균 기온 - 주가 변화: 하루하루의 주식 가격 - 인구 변화: 연도별 대한민국 인구수 - 성적 변화: 학기별 나의 평균 점수

    예시로 확인 ✅

    같은 데이터를 막대 그래프와 선 그래프로 그렸을 때의 차이:

    막대 그래프 → "각 달의 기온이 몇 도인지" 비교에 유리
    선 그래프 → "기온이 어떻게 오르고 내리는지" 흐름 파악에 유리

    시간 데이터에는 선 그래프가 훨씬 자연스럽습니다.

    개념 3: 오렌지3 Geo Map 위젯¶

    오렌지3에는 위도·경도 데이터를 지도 위에 바로 시각화할 수 있는 Geo Map 위젯이 내장되어 있습니다.

    flowchart LR A[📂 CSV 파일\n위도·경도 포함] --> B[File 위젯] B --> C[Geo Map 위젯] C --> D[🗺️ 지도 시각화\n완성!] style A fill:#e8f4f8,stroke:#2196F3 style B fill:#fff3e0,stroke:#FF9800 style C fill:#e8f5e9,stroke:#4CAF50 style D fill:#fce4ec,stroke:#E91E63

    Geo Map 위젯의 주요 설정: - Latitude: 위도 컬럼 선택 - Longitude: 경도 컬럼 선택 - Color: 점의 색깔을 결정할 변수 선택 (예: 카테고리, 수치) - Size: 점의 크기를 결정할 변수 선택 (예: 매출액이 클수록 점이 크게)

    개념 4: 시각화 유형 선택 기준¶

    "어떤 그래프를 써야 할까?" — 이 질문이 실전에서 가장 중요합니다.

    flowchart TD A{데이터에\n어떤 정보가\n있나요?} --> B[위치/좌표] A --> C[시간 순서] A --> D[항목 비교] A --> E[부분과 전체] A --> F[두 변수 관계] B --> B1[🗺️ 지도 시각화\nGeo Map] C --> C1[📈 선 그래프\nLine Plot] D --> D1[📊 막대 그래프\nBar Chart] E --> E1[🥧 파이 차트\nPie Chart] F --> F1[⚫ 산점도\nScatter Plot] style B1 fill:#e3f2fd,stroke:#1565C0 style C1 fill:#e8f5e9,stroke:#2E7D32 style D1 fill:#fff8e1,stroke:#F57F17 style E1 fill:#fce4ec,stroke:#AD1457 style F1 fill:#f3e5f5,stroke:#6A1B9A

    💡 알아보기: 하나의 데이터가 여러 시각화 유형에 걸칠 수도 있습니다. 예를 들어 "연도별 지역별 인구 데이터"는 지도(공간 분포)로도, 선 그래프(시간 변화)로도 표현할 수 있습니다. 목적에 따라 선택하세요!

    🔨 따라하기¶

    Step 1: 실습 데이터 준비하기¶

    이번 실습에서는 두 가지 데이터를 사용합니다.

    데이터 A — 서울시 공공 와이파이 위치 (지도 시각화용) - 컬럼: 장소명, 위도, 경도, 구분 - 각 행이 와이파이 설치 위치를 나타냄

    데이터 B — 서울 월평균 기온 (선 그래프용) - 컬럼: 연도, 월, 평균기온 - 2019~2023년 월별 기온 데이터

    두 데이터 모두 아래 파이썬 코드로 직접 만들 수 있습니다. 코드를 실행하면 CSV 파일이 생성됩니다.

    import pandas as pd
import numpy as np

# 데이터 A: 서울 주요 지점 (예시 좌표)
wifi_data = {
    '장소명': ['광화문광장', '홍대입구역', '강남역', '잠실역', '신촌역',
               '이태원', '명동', '동대문', '여의도공원', '북한산입구'],
    '위도': [37.5759, 37.5571, 37.4979, 37.5133, 37.5596,
             37.5344, 37.5636, 37.5712, 37.5264, 37.6580],
    '경도': [126.9769, 126.9245, 127.0276, 127.1001, 126.9368,
             126.9942, 126.9823, 127.0100, 126.9246, 126.9808],
    '구분': ['공원', '역', '역', '역', '역',
             '상업', '상업', '상업', '공원', '공원']
}
pd.DataFrame(wifi_data).to_csv('wifi_locations.csv', index=False, encoding='utf-8-sig')

# 데이터 B: 서울 월평균 기온 (2019-2023 예시)
np.random.seed(42)
years = list(range(2019, 2024))
months = list(range(1, 13))
records = []
base_temps = [-2.5, 0.5, 6.2, 12.8, 18.3, 22.8, 27.5, 28.1, 22.6, 15.3, 7.2, 0.5]
for y in years:
    for m, bt in zip(months, base_temps):
        records.append({'연도': y, '월': m, '평균기온': round(bt + np.random.uniform(-1.5, 1.5), 1)})
pd.DataFrame(records).to_csv('seoul_temperature.csv', index=False, encoding='utf-8-sig')

print("✅ 두 CSV 파일이 생성되었습니다!")

    Step 2: 오렌지3로 지도 시각화 만들기¶

    ⚠️ 준비: 오렌지3에 Geo Map 위젯이 없다면 상단 메뉴 → Add-ons → Orange3-Geo 설치 후 재시작하세요.

    오렌지3 워크플로우 구성:

    flowchart LR A[File\n위젯] -->|wifi_locations.csv| B[Geo Map\n위젯] B --> C[Data Table\n위젯] style A fill:#fff3e0,stroke:#FF9800 style B fill:#e8f5e9,stroke:#4CAF50 style C fill:#e3f2fd,stroke:#2196F3

    설정 순서: 1. File 위젯 더블클릭 → wifi_locations.csv 불러오기 2. Geo Map 위젯 캔버스에 추가 → File과 연결 3. Geo Map 더블클릭해서 열기 4. 왼쪽 패널에서: - Latitude → 위도 선택 - Longitude → 경도 선택 - Color → 구분 선택 (공원/역/상업이 다른 색으로 표시됨) 5. 지도 위에 점이 나타나는지 확인!

    🔍 생각해보기: 공원, 역, 상업 지역의 점들이 어디에 몰려 있나요? 예상과 같았나요?

    Step 3: 파이썬 folium으로 지도 시각화 만들기¶

    오렌지3 없이 파이썬으로도 같은 지도를 그릴 수 있습니다.

    import folium
import pandas as pd

# 데이터 불러오기
df = pd.read_csv('wifi_locations.csv')

# 색상 매핑
color_map = {'공원': 'green', '역': 'blue', '상업': 'red'}

# 서울 중심 좌표로 지도 생성
m = folium.Map(location=[37.5665, 126.9780], zoom_start=12)

# 각 위치에 마커 추가
for _, row in df.iterrows():
    folium.CircleMarker(
        location=[row['위도'], row['경도']],
        radius=10,
        color=color_map.get(row['구분'], 'gray'),
        fill=True,
        fill_opacity=0.7,
        popup=row['장소명']  # 클릭하면 장소명 표시
    ).add_to(m)

# HTML 파일로 저장
m.save('seoul_wifi_map.html')
print("✅ seoul_wifi_map.html 파일을 브라우저로 열어보세요!")

    브라우저에서 seoul_wifi_map.html을 열면 인터랙티브 지도가 나타납니다. 점을 클릭하면 장소명이 팝업으로 뜹니다!

    import pandas as pd
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.family'] = 'Malgun Gothic'  # 한글 폰트 설정
matplotlib.rcParams['axes.unicode_minus'] = False

# 데이터 불러오기
df = pd.read_csv('seoul_temperature.csv')

# 그래프 그리기
plt.figure(figsize=(12, 6))

colors = ['#e74c3c', '#3498db', '#2ecc71', '#f39c12', '#9b59b6']

for i, year in enumerate(sorted(df['연도'].unique())):
    year_data = df[df['연도'] == year].sort_values('월')
    plt.plot(
        year_data['월'],
        year_data['평균기온'],
        marker='o',
        label=f'{year}년',
        color=colors[i],
        linewidth=2
    )

plt.title('서울 월평균 기온 변화 (2019-2023)', fontsize=16, fontweight='bold')
plt.xlabel('월', fontsize=12)
plt.ylabel('평균기온 (°C)', fontsize=12)
plt.xticks(range(1, 13), [f'{m}월' for m in range(1, 13)])
plt.axhline(y=0, color='gray', linestyle='--', alpha=0.5)  # 0도 기준선
plt.legend(loc='upper left')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('seoul_temperature_line.png', dpi=150)

print("✅ 선 그래프가 완성되었습니다!")

    📝 전체 코드¶

    두 시각화를 한 화면에 함께 보여주는 통합 코드입니다.

    import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams['font.family'] = 'Malgun Gothic'
matplotlib.rcParams['axes.unicode_minus'] = False

# ── 데이터 생성 ──────────────────────────────────────
np.random.seed(42)
years = list(range(2019, 2024))
base_temps = [-2.5, 0.5, 6.2, 12.8, 18.3, 22.8, 27.5, 28.1, 22.6, 15.3, 7.2, 0.5]
records = []
for y in years:
    for m, bt in zip(range(1, 13), base_temps):
        records.append({'연도': y, '월': m,
                        '평균기온': round(bt + np.random.uniform(-1.5, 1.5), 1)})
df_temp = pd.DataFrame(records)

# ── 선 그래프 ────────────────────────────────────────
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

colors = ['#e74c3c', '#3498db', '#2ecc71', '#f39c12', '#9b59b6']
ax = axes[0]
for i, year in enumerate(sorted(df_temp['연도'].unique())):
    yd = df_temp[df_temp['연도'] == year].sort_values('월')
    ax.plot(yd['월'], yd['평균기온'],
            marker='o', label=f'{year}년',
            color=colors[i], linewidth=2)
ax.set_title('서울 월평균 기온 변화', fontsize=14, fontweight='bold')
ax.set_xlabel('월')
ax.set_ylabel('평균기온 (°C)')
ax.set_xticks(range(1, 13))
ax.set_xticklabels([f'{m}월' for m in range(1, 13)])
ax.axhline(y=0, color='gray', linestyle='--', alpha=0.5)
ax.legend(loc='upper left', fontsize=9)
ax.grid(True, alpha=0.3)

# ── 지도 대신: 위도-경도 산점도 (matplotlib) ─────────
wifi_data = {
    '장소명': ['광화문', '홍대', '강남역', '잠실', '신촌',
               '이태원', '명동', '동대문', '여의도', '북한산'],
    '위도': [37.5759, 37.5571, 37.4979, 37.5133, 37.5596,
             37.5344, 37.5636, 37.5712, 37.5264, 37.6580],
    '경도': [126.9769, 126.9245, 127.0276, 127.1001, 126.9368,
             126.9942, 126.9823, 127.0100, 126.9246, 126.9808],
    '구분': ['공원', '역', '역', '역', '역',
             '상업', '상업', '상업', '공원', '공원']
}
df_wifi = pd.DataFrame(wifi_data)
color_map = {'공원': '#2ecc71', '역': '#3498db', '상업': '#e74c3c'}
ax2 = axes[1]
for cat, grp in df_wifi.groupby('구분'):
    ax2.scatter(grp['경도'], grp['위도'],
                c=color_map[cat], s=150, label=cat, edgecolors='white', linewidth=1.5)
    for _, row in grp.iterrows():
        ax2.annotate(row['장소명'],
                     (row['경도'], row['위도']),
                     textcoords='offset points', xytext=(5, 5), fontsize=8)
ax2.set_title('서울 주요 지점 분포\n(경도=X축, 위도=Y축)', fontsize=14, fontweight='bold')
ax2.set_xlabel('경도 (동쪽 →)')
ax2.set_ylabel('위도 (북쪽 →)')
ax2.legend()
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('chapter08_visualization.png', dpi=150, bbox_inches='tight')
plt.show()
print("✅ 통합 시각화 완성!")

    ⚠️ 자주 하는 실수¶

    실수 1: 위도와 경도를 반대로 입력한다

    위도(Latitude)는 남북 방향, 경도(Longitude)는 동서 방향입니다. folium에서 location=[위도, 경도] 순서인데, 반대로 입력하면 점이 엉뚱한 곳에 찍힙니다.

    # ❌ 잘못된 예 (경도, 위도 순서 반대)
folium.Map(location=[126.9780, 37.5665])

# ✅ 올바른 예 (위도, 경도 순서)
folium.Map(location=[37.5665, 126.9780])

    실수 2: 시간 순서 데이터에 막대 그래프를 사용한다

    월별 기온 같은 연속적인 시간 데이터에 막대 그래프를 쓰면 "흐름"이 보이지 않습니다. 각 막대가 독립된 값처럼 보여서 변화 추이를 읽기 어렵습니다. 시간 축 데이터에는 선 그래프를 기본으로 선택하세요.

    실수 3: 한글이 깨진다

    matplotlib에서 한글을 표시하려면 반드시 폰트 설정이 필요합니다.

    # 반드시 그래프 코드 앞에 추가!
import matplotlib
matplotlib.rcParams['font.family'] = 'Malgun Gothic'   # Windows

matplotlib.rcParams['axes.unicode_minus'] = False       # 마이너스 부호 깨짐 방지

    실수 4: 데이터 없이 시각화 유형부터 결정한다

    "파이 차트가 예뻐 보이니까 쓸게요"는 잘못된 접근입니다. 항상 데이터의 성격과 전달하고 싶은 메시지를 먼저 정하고, 그에 맞는 시각화를 선택하세요.
